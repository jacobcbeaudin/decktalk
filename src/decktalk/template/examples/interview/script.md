# __TITLE__: narration script

Each "## N." section is one cut of the video. Bracketed directions are not spoken: `[beat]` is a
short pause, `[pause 1]` is a one second pause, and anything else in brackets is a note to
yourself. A line holding only `[voice NAME]` hands what follows to that voice until the next such
line or the next section, and a section that names a voice names one before every turn.

---

## 1. Welcome

[Scene 1. The title, then the two voices, then the table each one is.]

Welcome to the interview. [beat] Two voices read this film, a narrator and a guest. [beat]
Each of them is a table in the project file.

## 2. The interview

[Scene 2. The question, then each answer as the guest gives it.]

[voice narrator]

How do you write a film one sentence at a time?

[voice guest]

I write the sentence first. [beat] Then the picture waits for it.

[pause 1]

[voice narrator]

And when a sentence changes?

[voice guest]

Only that turn is voiced again. [beat] Everything else keeps its take.

## 3. Close

[Scene 3. The closing line and the end card.]

That is a dialogue. [beat] The next section always starts with the narrator again.
[beat] Make your own at decktalk dot AI.
