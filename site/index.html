Narrated presentations, cut to the word.

You write a markdown script and plain HTML slides. Your cloned voice reads the script. DeckTalk produces one mp4 in which every reveal lands on the word that introduces it. Change a sentence, and only that section is voiced again.

How it works

The script is the edit.

Narration comes back with a time for every word, so a reveal follows a phrase rather than a second. Change a sentence, and only that section is voiced again. Follow one cue through the four files.

01 WRITE
script.md
## 1. Open
The curve rises, then the
number lands. [beat] You
just watched DeckTalk.

A script in markdown

One heading starts one section. Bracketed directions are not spoken.

02 NARRATE
build/audio/01-open.words.json
{ "word": "curve",
  "start": 0.42 }
cues.json
{ "cue": "1.1curve",
  "on": "curve" }

Your voice reads it

ElevenLabs returns the audio and a timestamp for every word. A cue names a spoken phrase, and DeckTalk resolves it to the second the word starts.

03 RECORD
deck/index.html
<path data-cue="1.1curve"
      data-fx="draw"/>
<div data-cue="1.1number"
     data-fx="pop">3×</div>

Slides reveal on cue

Chromium records the plain HTML, and the page runtime shows each step when its word is spoken.

04 ASSEMBLE
$ decktalk build
[cut ] 01 -> 01-section.mp4
[caps] 32 cues -> srt, vtt
cue          at  offset
1:1.1curve 0.42  -20ms

Cut to the frame

ffmpeg cuts every section to the frame at 0.42 s, mixes the sound, and verify measures each reveal against its word.

What you get

Built for the tenth edit, not the first take.

[lead] 01 trim 1.440s

Frame-exact cuts

Each recording opens on a magenta cover until narration starts. The cut is measured from the frames, not from a timer.

[skip] 01-open.mp3 unchanged

Cached narration

Sections are hashed by text. An edit re-synthesizes only the sections that changed, so you pay per change, not per build.

[mix ] 3 audio input(s)

A soundscape

An underscore ducks under speech, ambience beds and effects land on cues, and the mix meets streaming loudness. Every part is optional.

1:1.1number -40ms changed

Verified output

Black or truncated recordings stop before assembly. A cue that cannot be found stops the build. A check proves each cue moved pixels.

From install to a first video.

The scaffold is the demo. A silent build takes a few minutes, because recording runs in real time. Build it silently first, and add your ElevenLabs voice when you are ready.

$ uv tool install decktalk && decktalk setup
$ decktalk init my-lesson && cd my-lesson
$ decktalk build --silent   # no key needed
$ decktalk build            # your voice
