Install

Narrated video from a script, in your own voice.

Every picture lands on its word.

A video is the one document you cannot edit a sentence of. DeckTalk ties every picture to a phrase of the narration instead of to a second on a timeline, so you change the sentence and build again.

Made with DeckTalk from this script · a 0:35 cut of the full 0:38 film · a fictional pitch

How it works

A cue names a word or a phrase, not a second.

Five chapters, and the film above stays with you through all of them. They follow one line of it: "Twenty minutes for her. Twenty minutes for you."

1 of 5

You write the script.

2 of 5

Your voice reads it, with a time for every word.

3 of 5

A cue names the word or phrase each picture waits for.

4 of 5

The slide is plain HTML, and each picture carries its cue.

5 of 5

A browser films the slide, and every landing is measured.

    Install
    
    
    Three lines to a first film.
    
    
    The first line brings its own Python, so there is nothing to install before it, and nothing to sign up for. Chromium and ffmpeg arrive on the first build, which says so before it downloads them. The last line writes an mp4.
    
    
    
    Once per machine
    
    
      
      
    1. 
        
      $ curl -LsSf https://decktalk.ai/install.sh | sh
      
        Installs uv, then DeckTalk. It never runs sudo, and it is served from a URL so you can read it first. If the command is not found afterwards, open a new shell.
      
      2. 
    
    
    
    For each film
    
    
      
      
    1. 
        
      $ decktalk init my-pitch
      
        
        Writes a whole working project rather than a stub: a three-section script, the cues, the slide page, decktalk.toml, .env.example, a .gitignore, the runtime and the KaTeX the page loads, an AGENTS.md, and six skills, in fourteen files, linked into .claude/skills so a coding agent can drive all of it. Nothing in it has to be deleted first.
      
      2. 
      
    2. 
        
      $ cd my-pitch && decktalk build --no-voice
      
        
        Recording runs in real time, so the build takes about as long as the film and a little more: 64 seconds on one M5 Pro, for the starter's 44 second video. It ends on the path of build/out/my-pitch.mp4, with placeholder narration and no key.
      
      3. 
    
    
    
    For your own voice, copy .env.example to .env, add an ElevenLabs key and a voice id, and build again. Any ElevenLabs voice works, including a clone of your own.
    
    
    Chromium and ffmpeg are fetched by the build that needs them, one time per machine. decktalk install fetches them up front instead, for a Docker layer, a CI cache or a machine about to go offline, and on Linux it installs Chromium's system libraries, which is the one thing here that asks for sudo.
    
    
    If you already have uv, uv tool install decktalk is the same install. Every project carries six skills, in fourteen files, one skill each for the script, the slides, the cues, the build, the fixes and a revision, so a coding agent can write the files, read the JSON every command prints, and fix what it finds. Start with the quickstart.
