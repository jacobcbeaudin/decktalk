Install

Four commands to a first film.

The first line brings its own Python, so there is nothing to install before it. Chromium and ffmpeg come with decktalk install, and the first build needs no key. Your own voice needs an ElevenLabs key and a voice id. Any ElevenLabs voice works, including a clone of your own.

  1. $ curl -LsSf https://decktalk.ai/install.sh | sh
    Installs uv, then DeckTalk. Read the script first — that is why it is served from a URL. If you already have uv, uv tool install decktalk does the same thing.
  2. $ decktalk install
    Fetches Chromium and ffmpeg, once per machine. On Linux it asks for sudo once, for Chromium's system libraries.
  3. $ decktalk init my-pitch
    Writes a starter script, cues, a slide page, decktalk.toml and .env.example.
  4. $ cd my-pitch && decktalk build --no-voice
    Builds the film with placeholder narration and no key. Copy .env.example to .env, add your ElevenLabs key and voice id, and build again for your voice.
