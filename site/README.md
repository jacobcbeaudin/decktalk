# decktalk.ai

The homepage. Static HTML, CSS and one script, with nothing to build, so the existing Cloudflare
Workers Builds deploy of `site/` serves it as it is.

## Files

- Every internal link points at the extensionless path (`/how`, `/films/halfway`, `/`), because
  the deploy strips the extension and answers `/how.html` with a 307 to `/how`. A link written with
  the extension still works, and costs every visitor who follows it a round trip. The canonical and
  `og:url` of each page name the same extensionless URL.
- `index.html` is the landing page: the hero, the films, the invitation to `/how` and the
  install commands. `how.html` is the explanation: how it works and the edit section, ending on the one-line install and a next line. `films.html` is the catalogue, one card per film, ending the same way. It loads `app.js` for the copy button and nothing else. They share
  `styles.css` and `app.js`, and `app.js` runs each part only on the page that carries its DOM, so
  neither page throws on the way past a section it does not have.
- `tokens.css` holds the brand's colour, type and motion tokens and is generated by
  `scripts/build_assets.py`, as are `favicon.svg`, the favicon PNGs and `og.png`.
- `data.js` and `stage.js` are generated by `scripts/build_homepage_data.py` from the Halfway
  build: the words with their times, the cues with their times and what each one shows, the band
  lines, the stage lines `decktalk build` printed for the run `data.js` names with what each
  stage did to each section, its cost line, the verify offsets, and the deck's own scenes
  and styles. The hero replays those scenes as HTML and SVG under the real recorded take, so it is
  a pure function of time and loads no video. Do not edit them by hand.
- `media/` holds the small derived files: the film posters as WebP and the films' captions,
  copied here so the text tracks are same-origin. The build script also writes the voice clips
  here (the hero's voice, the four takes laid out as the film lays them out at the film's -16 LUFS,
  and the section 3 take before and after the edit), but mp3s are not in git: the page streams
  them from media.decktalk.ai under the digest-carrying names `data.js` holds, which the script
  prints as an upload list.
- `fonts/` holds the self-hosted subsets of Instrument Serif (400, the headings), Bricolage
  Grotesque (500), Instrument Sans (400 to 700) and IBM Plex Mono (400 and 500), all OFL. Each is a
  Google Fonts latin file cut to the printable ASCII range plus a few punctuation marks.
- `films/` holds one page per film, with the film, the one-line install and its script. The film pages load `app.js` for the copy button, and their styles live in `styles.css` beside everything else's.
- `_headers` serves `install.sh` as text, so a browser shows the script rather than downloading
  it. Cloudflare's static assets read it. It names no account, zone or credential.

## Films

Videos are never in git. Each film streams from media.decktalk.ai under a name that carries the
first twelve hex digits of its SHA-256, for example `decktalk-halfway-74b61f590968.mp4`. To ship a
new cut, upload it under its new name, then change every `src` that names it, its poster and its
captions in the same commit.

The host of `media/` and of the films must answer Range requests (Cloudflare does). Without them a seek
while the voice plays snaps the audio to 0, and the page then drops to silent from the chosen second.
Python's `http.server` answers none, so review the page from a Range-capable server.

## Checks

`scripts/check.py` runs biome over `app.js` and the asset check over the generated tokens and
favicons. Render both pages with Playwright at 1440 by 900 and 390 by 844 before merging: the whole
hero, from the top of the nav to the bottom of the transport, must fit inside 900 css px on the
desktop size, and the stage must start inside the first 300 css px on the phone size. Load each
page with a console listener as well: `app.js` is one script over two pages, and the guard that
reveals the page when something throws must never have to fire.
