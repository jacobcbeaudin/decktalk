---
title: Add a clip section
description: Play a video clip with its own audio as an opening, between page sections, or as a close.
---

A clip section plays a video file of your own, with its own audio, as one section of the video. Use this guide
to open on camera, to add B-roll between page sections, or to close on a clip.

## Before you start

The steps use the scaffold that `decktalk init` writes. The scaffold has no clip section. Its `decktalk.toml`
has a section 0 in comments, which opens the video on a clip.

## Add a clip between two page sections

These steps add a clip section 4 to a new scaffold named `clip-lesson`. The edit and the close become sections
5 and 6.

<Steps>
  <Step title="Create a scaffold">
    ```console
    decktalk init clip-lesson
    ```
  </Step>

  <Step title="Go into the project">
    ```console
    cd clip-lesson
    ```
  </Step>

  <Step title="Add the clip section to decktalk.toml">
    Paste this table after the section 3 table.

    ```toml decktalk.toml
    [[section]]
    number = 4
    title = "Chips"
    clip = "media/chips.mp4"
    slate_seconds = 4
    optional = true         # plays the slate under --strict until the clip is in place
    ```

    - `clip` names your video file, relative to the project.
    - `slate_seconds` sets how long the slate plays while the file is missing.
    - `optional = true` lets `--strict` play the slate. The next section explains it.
  </Step>

  <Step title="Renumber the later sections in decktalk.toml">
    Change `number = 4` to `number = 5` in the table titled "The edit". Then change `number = 5` to `number = 6` in
    the table titled "Close".
  </Step>

  <Step title="Add the heading to script.md">
    Replace `## 4. The edit` with these lines, and change `## 5. Close` to `## 6. Close`.

    ```md script.md
    ## 4. Chips

    [The clip at media/chips.mp4 plays here, with its own sound.]

    ## 5. The edit
    ```

    The voice speaks nothing in a clip section, so the body can be a stage direction.
  </Step>

  <Step title="Renumber the section keys in cues.json">
    Rename the key `"5"` to `"6"`. Then rename the key `"4"` to `"5"`.

    The cue ids stay the same. They start with a scene number, and the scenes of the page do not change.
  </Step>

  <Step title="Build the video">
    Run a silent build.

    ```console
    decktalk build --silent
    ```

    {/* sample: decktalk build --silent in clip-lesson after the steps above, with no media/chips.mp4 (assemble lines) */}
    ```text
    [cut ] 03  03-scene.webm (lead 1.36s trimmed) -> 03-section.mp4  (132.000s)
    section 04: media/chips.mp4 missing; slate for 4s (drop your clip at that path; the section is optional, so --strict allows the slate)
    [cut ] 04  slate -> 04-section.mp4  (4.000s)
    [cut ] 05  05-scene.webm (lead 1.44s trimmed) -> 05-section.mp4  (30.920s)
    ```

    Each section gets a `[cut ]` line. The clip file does not exist yet, so section 4 plays a titled slate for 4 s.
  </Step>

  <Step title="Put the clip file in place">
    Save your video as `media/chips.mp4`. If you have no video, make a 4 s test clip. This command needs `ffmpeg`
    on your PATH.

    ```console
    ffmpeg -f lavfi -i testsrc2=size=1920x1080:rate=25 -f lavfi -i sine=frequency=440 -t 4 -pix_fmt yuv420p media/chips.mp4
    ```

    - A clip that is not 1920 by 1080 is scaled to fit and padded with black.
    - A clip with no audio track plays silent, and `assemble` prints a warning.
  </Step>

  <Step title="Cut the clip into the video">
    A new clip file changes no narration and no recording, so run only `assemble`.

    ```console
    decktalk assemble
    ```

    {/* sample: decktalk assemble in clip-lesson after the test clip above is in place (cut lines of sections 3 to 5) */}
    ```text
    [cut ] 03  03-scene.webm (lead 1.36s trimmed) -> 03-section.mp4  (132.000s)
    [cut ] 04  chips.mp4 (own audio) -> 04-section.mp4  (4.000s)
    [cut ] 05  05-scene.webm (lead 1.44s trimmed) -> 05-section.mp4  (30.920s)
    ```

    Check that section 4 reads `chips.mp4 (own audio)`. Then run `decktalk verify` to check the video.
  </Step>
</Steps>

## Build with --strict

`--strict` on `build` or `assemble` turns a missing clip into an error. A clip section with `optional = true`
still plays its slate.

Before the test clip was in place, `decktalk assemble --strict` exited 0 and printed this warning for section 4.

{/* sample: decktalk assemble --strict in clip-lesson with optional = true and no media/chips.mp4 */}
```text
section 04: media/chips.mp4 missing; slate for 4s (drop your clip at that path; the section is optional, so --strict allows the slate)
```

A clip section without `optional = true` fails under `--strict` when its file is missing. The command exits 1.

{/* sample: decktalk assemble --strict in clip-lesson after deleting optional = true, with no media/chips.mp4, error line */}
```text
error: section 4: clip missing: ~/clip-lesson/media/chips.mp4. Put your clip at that path, or set optional = true on the section to play its slate under --strict.
```

After your clip is in place, delete the `optional` line. `--strict` then catches the file if it goes missing
later.

## How the narration splits

`build/audio/narration.mp3` holds the spoken sections back to back, with no gap for a clip. `assemble` splits the
narration at each clip between page sections.

  <img className="hidden dark:block" src="/images/narration-split-dark.svg" alt="Lanes on one time axis. - Each part of the narration starts where its first page section starts in the video.
- No caption covers a clip section, unless the section sets `words`. [Caption the speech in a clip](#caption-the-speech-in-a-clip) explains it.
- A clip section gets its own chapter, unless the section before it has the same title.

Example: in the silent build of `clip-lesson`, section 5 starts at 170.60 s in `timeline.json` and at 174.60 s
in the final mp4. The 4 s clip of section 4 sits between them. [Build artifacts](/reference/artifacts#time-bases)
explains the two time bases.

{/* sample: decktalk status in clip-lesson after the steps above, section rows */}
```text
  03  deck/lesson.html?scene=3                 rec cut
  04  clip media/chips.mp4                         cut
  05  deck/index.html?scene=4                  rec cut
```

The narration does not depend on the length of a clip. After you replace a clip file, run only `decktalk assemble`,
then `decktalk verify`.

## The clip's sound

The clip's own audio joins the mix at its section start.

- The audio is trimmed to the clip's picture.
- The audio fades in and out over 20 ms, so a cut never clicks.
- The narration is silent while the clip plays.
- The underscore ducks under the whole clip. [Sound](/concepts/sound#ducking) explains ducking.

`verify` checks the start of a clip section, but a clip section has no cut row. The click search of the a/v check
never reaches into a clip's audio.

## Caption the speech in a clip

The captions come from the narration's word times, so a clip's own speech has no captions by default. Set
`words` on the clip section to caption it.

1. Write a words file for the clip. It is a JSON list with one object per word, in seconds after the clip starts.

   ```json media/interview.words.json
   [
     { "word": "Watch", "start": 0.15, "end": 0.42 },
     { "word": "it.", "start": 0.48, "end": 0.71 }
   ]
   ```

   Give each word its own punctuation and case. The captions break at the sentence ends it marks.

2. Name the file in the clip section.

   ```toml decktalk.toml
   [[section]]
   number = 4
   title = "Interview"
   clip = "media/interview.mp4"
   words = "media/interview.words.json"
   ```

3. Run `decktalk assemble`.

- A word that starts after the clip's picture ends has no caption.
- A slate or a clip with no audio track has no captions.
- If the words file is missing, `assemble` prints a warning and the clip has no captions.

A `NN-slug.words.json` file from `build/audio` has this format. A clip cut from an earlier build can reuse its
words, shifted to the clip's start.

## Keep one chapter across several sections

Each section starts a chapter. Consecutive sections with the same `title` share one chapter instead. Give a clip and
the page sections around it the same title, such as `title = "The edit"`, and the video shows one chapter that
spans all of them.

## Choose where the clip plays

A clip section can sit anywhere in the order of sections.

| Position | Example | What the narration does |
|---|---|---|
| Before the first page section | section 0 | The narration starts with the first page section, after the clip. |
| Between two page sections | section 4 of `clip-lesson` | The narration pauses for the clip. It continues on the first frame of the next page section. |
| After the last page section | a closing clip | The narration has ended before the clip starts. |

- `cues.json` names the cues of a section by its section number, such as `"5"` for the edit in `clip-lesson`.
- A section's `scene` names the scene in the page. Section 5 of `clip-lesson` plays scene 4, so its cue ids start
  with `4.1`.
- If you add or remove a clip section, renumber the sections in `decktalk.toml`, `script.md`, and `cues.json`. The
  pages stay the same.
- A renumbered section keeps its narration. `narrate` finds the take by its hash and copies it to the new file name.
- `hold_seconds` is allowed only on the last page section.

## Open the video on a clip

These steps turn on section 0 of a scaffold, such as `my-lesson` from the [quickstart](/quickstart). Section 0
needs no renumbering.

<Steps>
  <Step title="Uncomment section 0 in decktalk.toml">
    Remove the leading `# ` from the five lines of section 0.

    ```toml decktalk.toml
    [[section]]
    number = 0
    title = "On camera"
    clip = "media/open.mp4"
    slate_seconds = 6       # a titled slate plays for this long when the file is missing
    ```
  </Step>

  <Step title="Dip the cut out of the clip to black">
    In the existing `[transition]` table, change `dips = []` to `dips = [[0, 1]]`.

    ```toml decktalk.toml
    dips = [[0, 1]]
    ```

    `dips` lists each cut that dips to black, as a `[from, to]` pair of section numbers. The scaffold sets
    `dips = []`, so every cut is straight. If you delete the key, every cut dips.
  </Step>

  <Step title="Add a heading to script.md">
    Add `## 0. On camera` above section 1. A clip section needs no heading, but the heading keeps the script in
    the order of the video.

    ```md script.md
    ## 0. On camera

    [Your clip at media/open.mp4 plays here, with its own sound.]

    ## 1. Open
    ```
  </Step>

  <Step title="Put the clip file in place">
    Save your video as `media/open.mp4`.

    If the file is not ready, skip this step. A missing clip plays a titled slate for `slate_seconds`, with the
    section title and the path where the file belongs.
  </Step>

  <Step title="Build the video">
    Run a silent build.

    ```console
    decktalk build --silent
    ```

    {/* sample: decktalk build --silent in a scaffold with section 0 turned on as above, with no media/open.mp4 (assemble lines) */}
    ```text
    section 00: media/open.mp4 missing; slate for 6s (drop your clip at that path)
    [cut ] 00  slate -> 00-section.mp4  (6.000s)
    [cut ] 01  01-scene.webm (lead 1.44s trimmed) -> 01-section.mp4  (17.800s)
    ```

    Section 0 has no `optional` key, so its warning ends with `(drop your clip at that path)`. `--strict` fails
    on this section until the file exists.
  </Step>
</Steps>
