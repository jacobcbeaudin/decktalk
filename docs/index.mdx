---
title: DeckTalk
description: Narrated presentations, cut to the word.
---

DeckTalk turns three inputs into one video. You write a markdown script. A cloned voice
reads it and returns a timestamp for every word. Your HTML slides name the phrase that
each reveal should land on. DeckTalk records the slides, cuts them to the narration, mixes
an optional soundscape, and publishes an mp4.
