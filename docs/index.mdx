  <div className="mt-20">
    <h2 className="text-2xl font-semibold tracking-tight text-zinc-900 dark:text-zinc-50">Follow one cue through the four files</h2>
    <p className="mt-2 max-w-3xl text-zinc-600 dark:text-zinc-400">
      A project is four files that refer to each other by one number and one id. These four snippets are simplified from the scaffold, and they follow the cue <code>3.1eq</code> from the spoken phrase to the frame.
    </p>

    <Columns cols={2}>
      <Card title="1. The script says it" icon="pen-line">
        The words under a `## N.` heading are what the voice says. A time budget on the heading is optional, and a `[beat]` is a short pause that the voice reads as a dash.

        ```md script.md
        ## 3. Gradient descent — 0:40 to 1:00

        The gradient points uphill, in the plane
        of the weights, so follow minus the
        gradient. [beat] Take a step, and the
        learning rate, eta, scales its length.
        ```
      </Card>
      <Card title="2. The cue names the phrase" icon="crosshairs">
        A cue pairs a cue id with the phrase it lands on. The cue resolves to the first word of the phrase, so the update rule appears on "learning".

        ```json cues.json
        { "cue": "3.1eq", "on": "learning rate" }
        ```
      </Card>
      <Card title="3. The project file maps the section" icon="file-code">
        Section 3 of the script is scene 3 of the page. DeckTalk records that scene and cuts it to the section's narration.

        ```toml decktalk.toml
        [[section]]
        number = 3
        title = "Gradient descent"
        page = "deck/index.html"
        scene = 3
        ```
      </Card>
      <Card title="4. The slide waits for the cue" icon="presentation-screen">
        An element with `data-cue` stays hidden until its cue fires. KaTeX typesets the `data-tex` value, and the plain text is the fallback.

        ```html deck/index.html
        <div class="math" data-cue="3.1eq" data-display
             data-tex="\\theta_{t+1} = \\theta_t - \\eta\\,\\nabla L(\\theta_t)">
          θ(t+1) = θ(t) − η ∇L(θ(t))
        </div>
        ```
      </Card>
    </Columns>

    <p className="mt-6 max-w-3xl text-zinc-600 dark:text-zinc-400">
      After the build, <code>decktalk verify 3:3.1eq</code> measures the finished video and reports how far from the cue the picture first changed. After a silent build the <code>a/v</code> column also measures the picture against the placeholder click at the cued word.
    </p>

    ```text
    check                 cue       at   chg %   ctl %   offset     a/v  result
    3:3.1eq             15.66    72.38    0.29    0.00    -20ms    -5ms  changed
    ```
