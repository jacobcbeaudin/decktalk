  <div className="mt-20">
    <h2 className="text-2xl font-semibold tracking-tight text-zinc-900 dark:text-zinc-50">Follow one cue through the four files</h2>
    <p className="mt-2 max-w-3xl text-zinc-600 dark:text-zinc-400">
      A project is four files that refer to each other by one number and one id. These four snippets come from the scaffold that <code>decktalk init</code> writes, and they follow the cue <code>3.1c</code> from the spoken phrase to the frame.
    </p>

    <Columns cols={2}>
      <Card title="1. The script says it" icon="pen-line">
        The words under a `## N.` heading are what the voice says. A time budget on the heading is optional, and a `[pause 3]` direction is three seconds of silence.

        ```md script.md
        ## 3. The derivative of x squared — 0:40 to 1:10

        [pause 3]

        Only two x is left.
        The derivative of x squared is two x.
        ```
      </Card>
      <Card title="2. The cue names the phrase" icon="crosshairs">
        A cue pairs a cue id with the phrase it lands on. The `offset` trails the word by a fifth of a second, so the answer appears as the words finish.

        ```json cues.json
        { "cue": "3.1c", "on": "Only two x", "offset": 0.2 }
        ```
      </Card>
      <Card title="3. The project file maps the section" icon="file-code">
        Section 3 of the script is scene 3 of the page. DeckTalk records that scene and cuts it to the section's narration.

        ```toml decktalk.toml
        [[section]]
        number = 3
        title = "The derivative of x squared"
        page = "deck/index.html"
        scene = 3
        ```
      </Card>
      <Card title="4. The slide waits for the cue" icon="presentation-screen">
        An element with `data-cue` stays hidden until its cue fires. KaTeX typesets the `data-tex` value, and the `pop` effect lands the answer.

        ```html deck/index.html
        <p class="math answer" data-cue="3.1c"
           data-fx="pop" data-display
           data-tex="\\frac{d}{dx}\\,x^2 = 2x">
          d/dx x^2 = 2x
        </p>
        ```
      </Card>
    </Columns>

    <p className="mt-6 max-w-3xl text-zinc-600 dark:text-zinc-400">
      After the build, <code>decktalk verify 3:3.1c</code> measures the finished video and reports that the picture changed ten milliseconds after the cue.
    </p>

    ```text
    check                 cue       at   chg %   ctl %   offset  result
    3:3.1c              31.27    63.35    0.32    0.00    +10ms  changed
    ```
