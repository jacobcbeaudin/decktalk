This quickstart installs DeckTalk and builds the scaffold video, first with no account and then with your voice. Only part 3 needs an ElevenLabs API key.

If an agent does these steps for you, give it the [Reference card](/reference/card).

## Before you start

- You need Python 3.12 or later.
- You need uv, pipx, or pip.
- On Linux, step 2 needs sudo or root.
- Part 3 needs an ElevenLabs API key and a voice id.

## Part 1: Install DeckTalk

<Steps>
  <Step title="Install DeckTalk" stepNumber={1}>
    Install the `decktalk` command with your Python installer.

    <Tabs>
      <Tab title="uv">
        ```console
        uv tool install decktalk
        ```

        uv is a Python package manager. If you do not have it, [install uv](https://docs.astral.sh/uv/getting-started/installation/) first.
      </Tab>
      <Tab title="pipx">
        ```console
        pipx install decktalk
        ```
      </Tab>
      <Tab title="pip">
        ```console
        python -m venv .venv && source .venv/bin/activate
        pip install decktalk
        ```

        On Windows, activate the environment with `.venv\Scripts\activate`.
      </Tab>
    </Tabs>

    {/* sample: uv tool install, last line */}
    ```text
    Installed 1 executable: decktalk
    ```

    Check that the installer names the `decktalk` executable.
  </Step>

  <Step title="Download Chromium, ffmpeg, and KaTeX" stepNumber={2}>
    `decktalk setup` downloads the tools that DeckTalk runs. Run it one time per machine.

    ```console
    decktalk setup
    ```

    {/* sample: decktalk setup, last lines, uv tool install on macOS */}
    ```text
    == ffmpeg / ffprobe
       ffmpeg  ~/.local/share/uv/tools/decktalk/lib/python3.13/site-packages/static_ffmpeg/bin/darwin_arm64/ffmpeg
       ffprobe ~/.local/share/uv/tools/decktalk/lib/python3.13/site-packages/static_ffmpeg/bin/darwin_arm64/ffprobe
    == KaTeX 0.18.7
       cached  ~/Library/Caches/decktalk/katex/0.18.7
    setup complete
    ```

    Check that the last line is `setup complete`. On Linux, this step asks for sudo. [What setup downloads](/requirements#what-setup-downloads) says where each download goes.
  </Step>

  <Step title="Check the tools" stepNumber={3}>
    `decktalk doctor` reports each tool that DeckTalk needs.

    ```console
    decktalk doctor
    ```

    {/* sample: decktalk doctor, uv tool install on macOS */}
    ```text
    python    ok      3.13.1 (~/.local/share/uv/tools/decktalk/bin/python)
    chromium  ok      151.0.7922.34
    ffmpeg    ok      ~/.local/share/uv/tools/decktalk/lib/python3.13/site-packages/static_ffmpeg/bin/darwin_arm64/ffmpeg
    ffprobe   ok      ~/.local/share/uv/tools/decktalk/lib/python3.13/site-packages/static_ffmpeg/bin/darwin_arm64/ffprobe
    config    ok      none (optional, at ~/Library/Application Support/decktalk/decktalk.toml)
    katex     ok      ~/Library/Caches/decktalk/katex/0.18.7
    ```

    Check that every row says `ok`. If a row does not, run `decktalk setup` again.
  </Step>
</Steps>

## Part 2: Build the scaffold without an account

<Steps>
  <Step title="Create the scaffold" stepNumber={4}>
    `decktalk init` writes the scaffold, a complete example project.

    ```console
    decktalk init my-lesson
    ```

    {/* sample: decktalk init my-lesson, run in ~ */}
    ```text
    created ~/my-lesson
      decktalk.toml  the plan: sections -> pages or clips, voice, mix, soundscape
      script.md      the narration (## N. sections)
      cues.json      which spoken phrase each visual lands on
      deck/          index.html, lesson.html, decktalk-runtime.js (open a page for its scene index)
      media/         your clips, b-roll, markers.json
    next: cp .env.example .env  (ELEVENLABS_API_KEY, ELEVENLABS_VOICE_ID), then `decktalk build`
          or `decktalk build --silent` to render with placeholder narration and no API key
    ```

    If you skipped step 2, run `decktalk setup` now, then run `init` in a new folder. `init` copies the cached KaTeX into the project.
  </Step>

  <Step title="Go into the project" stepNumber={5}>
    ```console
    cd my-lesson
    ```
  </Step>

  <Step title="Open the slides in a browser" stepNumber={6}>
    Open the scaffold's main page. This takes seconds, and you see the slides before you build.

    <Tabs>
      <Tab title="macOS">
        ```console
        open deck/index.html
        ```
      </Tab>
      <Tab title="Linux">
        ```console
        xdg-open deck/index.html
        ```
      </Tab>
      <Tab title="Windows">
        ```console
        start deck\index.html
        ```
      </Tab>
    </Tabs>

    <Frame caption="The scene index lists each scene of the page with its steps and cue ids.">
      <img src="/images/quickstart-index.png" alt="The page my-lesson in index mode. It lists scenes 1, 2, 4, and 5, each with a play link. Under each scene, one step shows its hold seconds and cue ids." />
    </Frame>

    Check that the page shows an index of its scenes and steps.
  </Step>

  <Step title="Build the video without an account" stepNumber={7}>
    A silent build uses estimated word times and a click track, so it needs no key. Recording runs in real time. On a MacBook Pro with Apple M5 Pro and 64 GB memory, this build took 224.4 seconds. Leave it running, and read [What the example video shows](#what-the-example-video-shows).

    ```console
    decktalk build --silent
    ```

    {/* sample: decktalk build --silent, fresh scaffold on macOS (the last line of the assemble log and the last line) */}
    ```text
    done: ~/my-lesson/build/out/my-lesson.mp4  (204.84s)  copy: my-lesson-20260913-1952.mp4
    built ~/my-lesson/build/out/my-lesson.mp4
    ```

    Check that the last line starts with `built`.
  </Step>

  <Step title="Play the video" stepNumber={8}>
    <Tabs>
      <Tab title="macOS">
        ```console
        open build/out/my-lesson.mp4
        ```
      </Tab>
      <Tab title="Linux">
        ```console
        xdg-open build/out/my-lesson.mp4
        ```
      </Tab>
      <Tab title="Windows">
        ```console
        start build\out\my-lesson.mp4
        ```
      </Tab>
    </Tabs>

    The video is 204.84 seconds long, in five sections, with a soft click on each word. [What the example video shows](#what-the-example-video-shows) describes each section.
  </Step>
</Steps>

## Part 3: Add your voice and change a sentence

If you have no ElevenLabs account, stop here. The silent video is a complete build.

<Steps>
  <Step title="Copy the example settings file" stepNumber={9}>
    <Tabs>
      <Tab title="macOS and Linux">
        ```console
        cp .env.example .env
        ```
      </Tab>
      <Tab title="Windows">
        ```console
        copy .env.example .env
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Set your key and voice id" stepNumber={10}>
    In `.env`, replace the two placeholders with your API key and voice id.

    ```dotenv .env
    ELEVENLABS_API_KEY=<your-elevenlabs-key>     # Profile, then API keys, on elevenlabs.io
    ELEVENLABS_VOICE_ID=<voice-id>               # the id on a voice's card under Voices
    ```

    A value that still starts with `<` counts as unset. DeckTalk never prints the key and never writes it under `build/`.
  </Step>

  <Step title="Build the video with your voice" stepNumber={11}>
    <Warning>`decktalk build` without `--silent` spends ElevenLabs credits. [What spends credits](/requirements#what-spends-credits) lists the cost.</Warning>

    ```console
    decktalk build
    ```

    {/* SAMPLE NEEDED (R5, voiced build): the narrate lines, one [tts ] line per spoken section, then the built line */}

    This build voices every section, because it never reuses the click track. Check that the last line starts with `built`.
  </Step>

  <Step title="Change one sentence" stepNumber={12}>
    In section 3 of `script.md`, add four words to one sentence.

    ```diff script.md
    -The height is the error. [beat]
    +The height is the error, so lower is better. [beat]
    ```
  </Step>

  <Step title="Build only section 3" stepNumber={13}>
    ```console
    decktalk build --only 3
    ```

    {/* SAMPLE NEEDED (R5, voiced build): the narrate log after the edit, with [skip] for sections 1, 2, 4, and 5 and [tts ] for section 3 */}

    DeckTalk voices and records only section 3 again. The other sections take their narration from the cache. [Rebuild one section](/guides/rebuild-one-section) says what each kind of edit runs again.

    <Tip>If you are not sure which sections changed, run `decktalk build`. It voices only the sections whose text changed.</Tip>
  </Step>

  <Step title="Check that a reveal starts on its word" stepNumber={14}>
    ```console
    decktalk verify 1:1.1bowl
    ```

    {/* SAMPLE NEEDED (R5, voiced build): the cue row for 1:1.1bowl */}

    Check that the result is `changed`. The offset column is the time from the cue time to the onset of the reveal, in milliseconds. [Verify](/reference/verify#cues) defines every column.
  </Step>
</Steps>

## What the example video shows

The scaffold is a short lesson in five sections. Each section names its page and its scene.

| Section | Plays | What it shows |
|---|---|---|
| 1. Open | `deck/index.html`, scene 1 | A bowl and a ball appear on their words. The ball steps down on each count word, and each count word's start time appears. |
| 2. How it works | `deck/index.html`, scene 2 | A script card and a slide card appear. A waveform runs under one line, and the slide card grows into the lesson. |
| 3. How AI learns | `deck/lesson.html`, scene 3 | A box of knobs guesses, and a meter shows its [error](/help/faq#what-does-the-lesson-mean-by-error). A ball steps down a bowl, and the lesson ends on chips that do the math. |
| 4. The edit | `deck/index.html`, scene 4 | The script gains four words, and DeckTalk voices only section 3 again. `verify` shows that the later cues moved with their words. |
| 5. Close | `deck/index.html`, scene 5 | The end card. |

The scaffold's `decktalk.toml` also has a section 0 in comments, which opens the video on a clip of your own. [Add a clip section](/guides/clip-section) shows how to use it.
