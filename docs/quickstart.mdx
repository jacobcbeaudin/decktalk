---
title: Quickstart
description: Install DeckTalk with uv, pipx, or pip, build the scaffold video without an API key, then add an ElevenLabs voice and build the narrated mp4.
icon: "play"
---

<Steps>
  <Step title="Install">
    DeckTalk needs Python 3.12 or later. Everything else arrives through Python packages
    and the downloads that `decktalk setup` makes. Playwright's package carries its own
    browser driver, and `static-ffmpeg` fetches ffmpeg and ffprobe for your platform. You do
    not need Node.

    <Tabs>
      <Tab title="uv">
        ```console
        uv tool install decktalk
        ```

        `uv` is a Python package manager from Astral. The command `uv tool install` puts a
        command-line tool in its own environment and on your PATH.
        [Install uv](https://docs.astral.sh/uv/getting-started/installation/) first if you
        do not have it.
      </Tab>
      <Tab title="pipx">
        ```console
        pipx install decktalk
        ```
      </Tab>
      <Tab title="pip">
        ```console
        python -m venv .venv && source .venv/bin/activate
        pip install decktalk
        ```
      </Tab>
    </Tabs>

    Then fetch the tools DeckTalk drives, once per machine, and confirm that they work.

    ```console
    decktalk setup     # headless Chromium, ffmpeg, and KaTeX, once per machine
    decktalk doctor    # reports each tool and exits 1 when one is missing
    ```

    ```text
    python    ok      3.13 (.venv/bin/python3)
    chromium  ok      <version>
    ffmpeg    ok      .venv/lib/python3.13/site-packages/static_ffmpeg/bin/darwin/ffmpeg
    ffprobe   ok      .venv/lib/python3.13/site-packages/static_ffmpeg/bin/darwin/ffprobe
    config    ok      none (optional, at ~/Library/Application Support/decktalk/decktalk.toml)
    katex     ok      ~/Library/Caches/decktalk/katex/<version>
    ```

    Run `setup` before `init`, because `init` copies the cached KaTeX into the project so
    that equations render with no network. [Requirements and costs](/requirements) says
    where each download goes and why Linux asks for sudo.
  </Step>

  <Step title="Scaffold and build">
    ```console
    decktalk init my-lesson && cd my-lesson
    decktalk build --silent          # every stage with placeholder narration, no key
    ```

    The `--silent` flag runs every stage with a placeholder track, a soft click at every
    estimated word start, and estimated word times. It needs no account and costs
    nothing, so use it to prove that a project builds before you spend credits. A first
    silent build takes a few minutes, because recording runs in real time. Each stage
    prints a table, and the build ends with the path of the video. The first silent build
    also warns that the underscore is missing. The scaffold's music comes from
    `decktalk soundscape`, which spends credits, and the video is complete without it.

    ```text
    sec    start    probe   YAVG   YMAX  result
     01     0.00     0.20    232    245  ok
     02    18.36    18.56    230    247  ok
     03    47.00    47.20    229    255  ok
     04   119.16   119.36    227    249  ok
     05   138.20   138.40    231    249  ok
    total 150.96s; 0 black section start(s)

    sec   cut at  before cut  result
     01    18.35   -130.2 dB  quiet
     02    47.01   -125.4 dB  quiet
     03   119.15   -130.2 dB  quiet
     04   138.21   -125.4 dB  quiet
     05   148.45   -120.0 dB  quiet

    built ~/my-lesson/build/out/my-lesson.mp4
    ```

    <Tabs>
      <Tab title="macOS">
        ```console
        open build/out/my-lesson.mp4
        ```
      </Tab>
      <Tab title="Linux">
        ```console
        xdg-open build/out/my-lesson.mp4
        ```
      </Tab>
      <Tab title="Windows">
        ```console
        start build\out\my-lesson.mp4
        ```
      </Tab>
    </Tabs>

    The scaffold is a short lesson in five sections. A cold open performs its own
    sentence, as a line of the script lights up word by word while the voice reads it. The
    second section shows three files and a voice tied by one id. A gradient descent lesson
    moves a ball down a three.js loss surface, builds the update rule in KaTeX, and shows
    a learning rate that zigzags, one that flies out, one that crawls, and one that settles
    at the minimum. In the fourth section one word of section 3 is edited, and the rebuild's
    log shows that only section 3 is voiced again. An end card closes on decktalk.app. All five are
    page sections, which DeckTalk records from `deck/index.html` and cuts to the narration.
    A commented-out section 0 shows how to open with a clip of your own, and
    [Add a clip section](/guides/clip-section) walks through it.
  </Step>

  <Step title="Add your voice">
    Copy `.env.example` to `.env` and replace the two placeholders.

    ```dotenv .env
    ELEVENLABS_API_KEY=sk_...        # Profile, then API keys, on elevenlabs.io
    ELEVENLABS_VOICE_ID=...          # the id on a voice's card under Voices
    ```

    Both values can also come from the environment. A value left as `<placeholder>`
    counts as unset. DeckTalk never prints the key and never writes it under `build/`.
    Then build the project again. This build voices every section, because a silent
    build's placeholders are never reused.

    ```console
    decktalk build
    ```

    <Note>You need an ElevenLabs API key.
    [Requirements and costs](/requirements) lists which commands spend credits, and the
    [FAQ](/help/faq#what-does-it-cost) gives the arithmetic.</Note>
  </Step>

  <Step title="Review">
    Open `deck/index.html` in any browser with no query string. The page shows an index of
    every scene and step. Add `?scene=2` to play a scene, `?step=2.1` to freeze one step
    with everything revealed, or `&hud=1` to overlay the clock.

    ```console
    decktalk shots                          # one PNG per step, under build/shots/
    decktalk shots --section 3 --at 22      # a frame from section 3 as it plays with its real cues
    decktalk verify 3:3.1eq                 # measures when the cue changed the picture in the mp4
    decktalk status                         # the timeline and what is built
    ```
  </Step>

  <Step title="Change a sentence">
    Make the edit that the scaffold's fourth section shows. In section 3 of `script.md`,
    change "For this lesson it is a bowl." to "For this lesson it is a valley." Then build
    again and read the narrate log.

    ```console
    decktalk build
    ```

    The log prints a `[skip]` line for sections 1, 2, 4, and 5, whose narration comes from
    the cache, and a `[tts ]` line for section 3. Change a sentence, and only that section is
    voiced again. A plain build records every section again in real time, and
    `decktalk build --only N` records only that section. The edit costs the characters of
    all of section 3, because the cache key is the section's whole text.

    When you know that only section 3 changed, the fast path records only that section. It
    still takes the other sections' narration from the cache, and it assembles and verifies
    the whole video.

    ```console
    decktalk build --only 3
    ```

    [Rebuild one section](/guides/rebuild-one-section) says what each kind of edit runs
    again.
  </Step>
</Steps>

## What is in a project

| Path | What it holds |
|---|---|
| `decktalk.toml` | The plan. One `[[section]]` per script section, the voice, the transitions, the mix, the soundscape prompts, and any tuning. [Reference](/reference/decktalk-toml). |
| `script.md` | The narration. Each `## N. Title` heading starts a section, and text in square brackets is a stage direction that is not spoken. [Reference](/reference/script-md). |
| `cues.json` | The phrase that each visual lands on. [Reference](/reference/cues-json). |
| `deck/` | Your pages, with `decktalk-runtime.js`, a vendored copy of KaTeX, and `vendor/three.min.js` for the scaffold's loss surface beside them. `deck/fonts/` holds Inter, Inter Tight, and JetBrains Mono as OFL woff2 files, declared with `font-display: block`, so a recorder with no network draws them rather than a fallback face. [Runtime reference](/reference/runtime). |
| `media/` | Your own clips and the underscore markers. |
| `.env` | The ElevenLabs key and voice id. Git ignores it. |
| `build/` | Everything DeckTalk generates, including the video, captions, and chapters. Git ignores it. [Artifacts](/reference/artifacts). |

<Tip>Write numbers and symbols in the script the way you want them spoken. A cue matches
the spoken words "learning rate", while the slide shows η.</Tip>
