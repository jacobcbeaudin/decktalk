A voiced take holds no sound above the level its sound end is measured at, so its turn plays silence. Only narrate raises it, on the run that makes the take.

This finding is a warning, and DeckTalk measures it from what the run produced.
Pass `--allow TAKE_SILENT` to carry on past it, and `--fail-on` to choose which severity fails a run.

The settings that move this verdict are `narration.sound_end_noise_dbfs`, `narration.sound_end_min_run_seconds`.
