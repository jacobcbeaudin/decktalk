A file the project names is not on disk.

This finding is an error, and DeckTalk judges it itself. `decktalk check` reports it when it judges the project's files before a build, `decktalk status` when it compares the files the project lists with the disk, `decktalk doctor` when it looks over the tools this machine has, and `decktalk assemble` when it cuts and mixes the film.
Pass `--allow FILE_MISSING` to carry on past it, and `--fail-on` to choose which severity fails a run.

## What to do

Write the file or correct the path the project names. For a tool file `decktalk doctor` names, run `decktalk install` or `decktalk doctor --fix`.

Troubleshooting says more under [A missing toolchain](/help/troubleshooting#a-missing-toolchain).
