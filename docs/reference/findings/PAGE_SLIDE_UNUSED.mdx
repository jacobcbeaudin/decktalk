No section plays this slide, so nothing on it reaches the film.

This finding is an error, and the page reports it from the browser. `decktalk record` reports it when it records the pages, and `decktalk verify` when it measures the finished film and reads back each recording log.
Pass `--allow PAGE_SLIDE_UNUSED` to carry on past it, and `--fail-on` to choose which severity fails a run.

## What to do

Have a section play the slide's scene, or delete the slide. `--allow PAGE_SLIDE_UNUSED` carries a run past it while the slide is still being wired up.
