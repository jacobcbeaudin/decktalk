A wait the page declared was rejected, so the runtime carried on without what it waited for.

This finding is an error, and the page reports it from the browser. `decktalk check` reports it when it judges the project's files before a build, `decktalk record` when it records the pages, and `decktalk verify` when it measures the finished film and reads back each recording log.
Pass `--allow PAGE_WAIT_REJECTED` to carry on past it, and `--fail-on` to choose which severity fails a run.

## What to do

Fix whatever the page asked the runtime to wait for. Open the page with `decktalk serve`, and the browser console shows why it rejected.

Troubleshooting says more under [A recording that opens black or runs short](/help/troubleshooting#a-recording-that-opens-black-or-runs-short).
