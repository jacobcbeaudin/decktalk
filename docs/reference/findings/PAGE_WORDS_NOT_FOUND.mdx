An element syncs to words the transcript does not hold, so word timing cannot start.

This finding is an error, and the page reports it from the browser. `decktalk record` reports it when it records the pages, and `decktalk verify` when it measures the finished film and reads back each recording log.
Pass `--allow PAGE_WORDS_NOT_FOUND` to carry on past it, and `--fail-on` to choose which severity fails a run.

## What to do

Make the element's text words the script really speaks in that section, which `decktalk words --section N` lists.

Troubleshooting says more under [A page the contract refuses](/help/troubleshooting#a-page-the-contract-refuses).
