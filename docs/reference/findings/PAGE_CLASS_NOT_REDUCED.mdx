A class change declares no reduced form, so a reduced render would animate anyway.

This finding is an error, and the page reports it from the browser. `decktalk check` reports it when it judges the project's files before a build.
Pass `--allow PAGE_CLASS_NOT_REDUCED` to carry on past it, and `--fail-on` to choose which severity fails a run.

The settings that move this verdict are `motion.reduce`.

## What to do

Make the page's stylesheet honour `prefers-reduced-motion` for that class, and look at it with `--set motion.reduce=true`.
