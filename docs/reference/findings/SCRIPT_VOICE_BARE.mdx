A note is exactly the name of a voice the project declares, so it plays as a beat rather than handing the turns after it to that voice.

This finding is a warning, and DeckTalk judges it itself. `decktalk check` reports it when it judges the project's files before a build.
Pass `--allow SCRIPT_VOICE_BARE` to carry on past it, and `--fail-on` to choose which severity fails a run.

## What to do

Write the direction as `[voice NAME]` rather than the bare name.

Troubleshooting says more under [A voice direction that names no voice](/help/troubleshooting#a-voice-direction-that-names-no-voice).
