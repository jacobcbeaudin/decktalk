The script holds a symbol the voice reads as its name rather than as the thing it means.

This finding is a warning, and DeckTalk judges it itself. `decktalk check` reports it when it judges the project's files before a build.
Pass `--allow SCRIPT_SPOKEN_SYMBOL` to carry on past it, and `--fail-on` to choose which severity fails a run.

## What to do

Write the symbol out as the voice must say it.
