The page loads an asset from a network origin, so the film depends on somebody else's server.

This finding is an error, and DeckTalk judges it itself. `decktalk check` reports it when it judges the project's files before a build, `decktalk record` when it records the pages, and `decktalk verify` when it measures the finished film and reads back each recording log.
Pass `--allow PAGE_CDN_ASSET` to carry on past it, and `--fail-on` to choose which severity fails a run.

## What to do

Download the asset into `deck/` and point the page at the local copy. For equations, link the KaTeX DeckTalk serves at `/__decktalk/katex/`.

Troubleshooting says more under [A page that loads an asset from a network origin](/help/troubleshooting#a-page-that-loads-an-asset-from-a-network-origin).
