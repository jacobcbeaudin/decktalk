A section's take is not on disk, so a placeholder plays in its place until its voice makes one.

This finding is a warning, and DeckTalk judges it itself. `decktalk narrate` reports it when it makes or keeps the narration takes.
Pass `--allow TAKE_MISSING` to carry on past it, and `--fail-on` to choose which severity fails a run.

## What to do

Run the command the message names. For a provider that bills it is `decktalk narrate --section N --spend`, and for a free provider that could not be reached, start its server and run `decktalk narrate --section N`.

Troubleshooting says more under [A take that is missing](/help/troubleshooting#a-take-that-is-missing).
