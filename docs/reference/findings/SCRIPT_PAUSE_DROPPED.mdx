The script asks for a timed pause the voice's model does not render, so a voiced run would drop it.

This finding is an error, and DeckTalk judges it itself. `decktalk check` reports it when it judges the project's files before a build.
Pass `--allow SCRIPT_PAUSE_DROPPED` to carry on past it, and `--fail-on` to choose which severity fails a run.

## What to do

Set the voice's model, `[voices.NAME] model` or its provider table's, to one that renders `[pause N]`, such as `eleven_multilingual_v2`, or write a `[beat]`, which every model reads.

Troubleshooting says more under [A script that is not ready to be voiced](/help/troubleshooting#a-script-that-is-not-ready-to-be-voiced).
