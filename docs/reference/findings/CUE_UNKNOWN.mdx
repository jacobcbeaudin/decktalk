cues.json lists a cue no page declares, so nothing plays it.

This finding is an error, and DeckTalk judges it itself. `decktalk check` reports it when it judges the project's files before a build, and `decktalk cue` when it resolves each cue phrase against the takes.
Pass `--allow CUE_UNKNOWN` to carry on past it, and `--fail-on` to choose which severity fails a run.

## What to do

Draw the element that declares the cue, correct the id, or delete the row. `--allow CUE_UNKNOWN` carries a build past a slide not drawn yet.

Troubleshooting says more under [An unresolved cue](/help/troubleshooting#an-unresolved-cue).
