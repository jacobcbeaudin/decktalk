A sound the `[score]` table declares has not been bought, so silence plays where it would until a run with --spend buys it.

This finding is a warning, and DeckTalk judges it itself. `decktalk score` reports it when it buys or keeps the score's sounds, and `decktalk assemble` when it cuts and mixes the film.
Pass `--allow SOUND_MISSING` to carry on past it, and `--fail-on` to choose which severity fails a run.

## What to do

Run `decktalk score --spend` to buy it, or `decktalk score --no-spend` to see its price first.

Troubleshooting says more under [A missing toolchain](/help/troubleshooting#a-missing-toolchain).
