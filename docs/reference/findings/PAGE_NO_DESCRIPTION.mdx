An element changes the picture and describes nothing, so the transcript loses the change.

This finding is an error, and DeckTalk judges it itself. `decktalk check` reports it when it judges the project's files before a build.
Pass `--allow PAGE_NO_DESCRIPTION` to carry on past it, and `--fail-on` to choose which severity fails a run.

## What to do

Add `data-describe` to the element, or add it empty to say the element is decorative.

Troubleshooting says more under [A page the contract refuses](/help/troubleshooting#a-page-the-contract-refuses).
