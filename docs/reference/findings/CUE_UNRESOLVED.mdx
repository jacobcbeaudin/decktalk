The cue's phrase is not spoken in its section, so there is no second to place it at.

This finding is an error, and DeckTalk judges it itself. `decktalk check` reports it when it judges the project's files before a build, `decktalk cue` when it resolves each cue phrase against the takes, and `decktalk verify` when it measures the finished film and reads back each recording log.
Pass `--allow CUE_UNRESOLVED` to carry on past it, and `--fail-on` to choose which severity fails a run.

## What to do

Change the row's `phrase` to words the section really speaks, which `decktalk words --section N` lists, or change the script.

Troubleshooting says more under [An unresolved cue](/help/troubleshooting#an-unresolved-cue).
