This page gives each DeckTalk word its one meaning. Write the word, and write it in that meaning
alone. Write it whole, because a short form such as bed, span, offset or stage belongs to no one
word.

## The six stages

They run in this order, and each is both a command and a call on a `Project`.

| Word | Meaning | Explained in |
|---|---|---|
| narrate | The stage that turns the script into spoken takes with a word clock. It writes `build/narrate/takes.json`, the take files and their words files. | [How it works](/concepts/how-it-works) |
| cue | The stage that turns each cue phrase into a second on its section clock. It writes `build/cue-times.json`. | [Cues](/concepts/cues) |
| record | The stage that records each page section in headless Chromium against those seconds. It writes `build/recordings/`. | [How it works](/concepts/how-it-works) |
| soundscape | The stage that generates the music, the ambience bed and the effects. It writes `build/soundscape/`. | [Sound](/concepts/sound) |
| assemble | The stage that cuts, mixes and encodes the sections into one film. It writes `build/final/`. | [How it works](/concepts/how-it-works) |
| verify | The stage that measures the finished film against the clock the earlier stages promised. It writes nothing. | [Verify](/reference/verify) |

## The page

| Word | Meaning | Explained in |
|---|---|---|
| scene | One `[data-scene]` wrapper in a deck page, holding the slides a section plays. | [The page contract](/concepts/page-contract) |
| slide | One `<template data-slide>` inside a scene, which the runtime clones when the slide mounts. | [The page contract](/concepts/page-contract) |
| container | An element whose children carry moments, so one cue can stagger or step through them. | [The page contract](/concepts/page-contract) |
| moment | One of the four things an element does, which are `data-in`, `data-back`, `data-front` and `data-out`. Each names a cue local to its slide. | [The page contract](/concepts/page-contract) |
| wire id | The id `cues.json` carries for a moment, which is the slide id, a colon and the local name the page writes. `data-in="expand"` inside `<template data-slide="4.1">` is the wire id `4.1:expand`. | [Cues](/concepts/cues) |
| cue | One row of `cues.json`, pairing a wire id with the spoken phrase its moment waits for. | [cues.json](/reference/cues-json) |

## The project

| Word | Meaning | Explained in |
|---|---|---|
| project | One directory holding `script.md`, `decktalk.toml`, `cues.json` and the deck pages, and the `build/` directory those four produce. | [decktalk.toml](/reference/decktalk-toml) |
| section | One numbered part of the script and the `[[section]]` table that pairs it with a scene or a clip. | [decktalk.toml](/reference/decktalk-toml) |
| take | One section's spoken audio, named by the digest of everything that changes it. Two sections with the same text and voice share one take. | [Build artifacts](/reference/artifacts) |
| clip | A video file of your own that a clip section plays with its own audio, and the file `decktalk clip` cuts out of a built section. | [Add a clip section](/guides/clip-section) |
| storyboard | The page at `build/storyboard.html` that freezes every slide at every cue, which is the checkpoint a person reads before credits are spent. | [CLI](/reference/cli) |
| soundscape | The generated sound beside the narration, which is the music, the ambience bed and the effects. | [Sound](/concepts/sound) |
| machine | This computer and this process, which is what holds the toolchain, the per-machine settings and the credential a voiced run uses. | [Python API](/reference/python-api) |

## A run and what it reports

| Word | Meaning | Explained in |
|---|---|---|
| run | One call that opens work, named by a run id that every result and every event line carries. Its lines are kept in `build/events/<run>.jsonl`. | [The JSON contract](/agents/json) |
| event | One JSON line saying what is happening while a run is still going, printed on stderr by `--events`. | [The JSON contract](/agents/json) |
| finding | One judgement DeckTalk made about the project, carrying a code, a sentence, a certainty, a location and often a fix. | [CLI](/reference/cli) |
| certainty | Whether a finding is wrong for sure or only probably wrong, which is `certain` or `uncertain`. `--fail-on` names the threshold a run fails at. | [The JSON contract](/agents/json) |
| fix | A change a finding carries that would resolve it, which edits files, turns a knob or runs a command. Its applicability says whether it may be applied without asking. | [The JSON contract](/agents/json) |
| spend | What a run of the voice costs or would cost, priced once and carried as an object with its state, its characters and its ceiling. | [Requirements and costs](/requirements) |

## The knobs

| Word | Meaning | Explained in |
|---|---|---|
| knob | One published setting with a default, a safe range, a unit and a hazard, which `decktalk config explain` prints whole. | [Configuration](/reference/configuration) |
| layer | One of the five places a knob's value can come from, which are the default, the per-machine file, `decktalk.toml`, the environment variable and `--set`. Each overrides the ones before it. | [Configuration](/reference/configuration) |
