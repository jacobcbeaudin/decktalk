These files are part of the public contract, and your own tools may read any of them.
The recorder passes each section's entry in `beats.json` to the page as `?beats=`. Every JSON file is written atomically, so a reader
never sees a partial file. Field names in the JSON match the dataclasses in
`decktalk.artifacts`.

```text
build/
  audio/   NN-slug.mp3, NN-slug.words.json, manifest.json, narration.mp3, timeline.json, beats.json, beats.anchors.json
  rec/     NN-scene.webm, NN-scene.json
  out/     NN-section.mp4, <name>.mp4, <name>-YYYYMMDD-HHMM.mp4, <name>.srt, <name>.vtt, <name>.chapters.txt, slates/
  shots/   step-<id>.png, step-<id>-cue-<cue>.png, section-NN-at-<S>s.png
  sfx/     ambience.mp3, <name>.mp3, and a .manifest.json beside each
  music/   underscore.mp3, its parts, and its manifest
```

## `build/audio/NN-slug.words.json`

A list of words with times within that section's mp3.

```json
[
 {
  "word": "The",
  "start": 0.7,
  "end": 1.158
 },
 {
  "word": "curve",
  "start": 1.178,
  "end": 1.636
 }
]
```

The first word of the first spoken section starts after the lead break. Punctuation is
stripped from each word.

## `build/audio/manifest.json`

One entry per narrated section. The `hash` is what the cache compares.

| Field | Meaning |
|---|---|
| `script`, `model`, `output_format` | The fields record what produced the audio. A silent build records `silent-placeholder` as the model. |
| `estimated`, `estimate_basis` | `estimated` is true after a silent build, and `estimate_basis` holds the pacing used, such as `150 wpm + declared pauses`. |
| `total_seconds` | The field holds the sum of the segments. |
| `segments.NN.index`, `.title` | The fields hold the section's number and title. |
| `segments.NN.file`, `.words_file` | The fields name the mp3 and the words file. |
| `segments.NN.hash` | The field holds the hash of the provider, the voice id, the model, the output format, the voice settings, and the text sent, or `silent` after a silent build. |
| `segments.NN.words`, `.est_seconds`, `.duration_seconds` | The fields hold the word count, the pacing estimate, and the real length. |
| `segments.NN.target_seconds`, `.speech_end_seconds`, `.tail_padded_seconds` | The fields hold the time budget from the heading, where speech ends, and how much silence was added. |
| `segments.NN.spoken` | The words the voice was given, without break tags, with the script's punctuation and case. Captions take their spelling from it, so they match the audio even after the script changes. A manifest without it falls back to the script. |

## `build/audio/timeline.json`

Section and word times, absolute within `narration.mp3`. `speech_end` is where the last
word ends, and the section runs on to `end` in silence.

```json
{
 "narration": "narration.mp3",
 "total_seconds": 148.45,
 "sections": {
  "01": {
   "title": "Open",
   "start": 0.0,
   "end": 18.35,
   "duration": 18.35,
   "speech_end": 17.88,
   "words": [
    {
     "word": "The",
     "start": 0.7,
     "end": 1.158
    }
   ]
  }
 },
 "estimated": true
}
```

## `build/audio/beats.json`

The resolved cues per section, as the string the page receives in `?beats=`. The seconds
are relative to the section's start, and a section with no resolved cue is left out.

```json
{
  "01": "1.1curve@1.18,1.1number@3.09,1.1mark@4.34,1.1md@7.87,1.1times@12.17,1.1cap@15.99",
  "05": "5.1made@2.33,5.1cap@2.8,5.1url@8.4"
}
```

## `build/audio/beats.anchors.json`

Each cue's word start without its `offset`, per section. `verify` uses it after a silent
build to find the click at the cued word, so a cue that trails its word by an offset is
still measured against the word's own click.

```json
{
  "01": { "1.1curve": 1.18, "1.1number": 3.09, "1.1mark": 4.04, "1.1md": 7.87, "1.1times": 12.17, "1.1cap": 15.99 }
}
```

## `build/rec/NN-scene.json`

The sidecar of a recording: what the recorder did for one section, and where narration
t=0 sits in the webm.

```json
{
  "url": "file:///home/me/my-lesson/deck/index.html?scene=1&beats=1.1curve%401.18%2C1.1number%403.09&words=The%400.70%2Ccurve%401.18&t0=signal",
  "requested_seconds": 18.65,
  "settle_seconds": 1.46,
  "load_seconds": 0.045,
  "lead_seconds": 1.505,
  "lead_in_seconds": 1.44,
  "lead_method": "cover (36 magenta frames)",
  "warnings": [],
  "page_errors": [],
  "frame_gaps": [],
  "sync_log": [{ "text": "The curve rises, then th", "cueAt": 0.009, "runAt": 0.7, "n": 7, "firstOn": 0.683 }]
}
```

| Field | Meaning |
|---|---|
| `url` | The field holds the page URL the recorder opened, including `scene`, `beats`, `words`, and `t0=signal`. |
| `requested_seconds` | The field holds how long the recording was asked to run, which is the section span plus `extra_seconds`. |
| `settle_seconds` | The field holds how long the recorder waited after load before it started the clock. |
| `load_seconds`, `lead_seconds` | The fields hold the recorder's wall-clock estimates of how long the page took to load and how long the recorder waited before the clock started. |
| `lead_in_seconds` | The field holds the time of the first clean frame after the magenta cover, written by `measure`. The assembler trims here. |
| `frame_gaps` | The list holds `[seconds, ms]` pairs, one for every gap longer than 100 ms between two page frames, copied from `window.__decktalk.frameGaps`. The seconds give where the gap ended after narration t=0, and a gap that ended before the clock started has `null` seconds. `check` reports `STALLED` when the part of a gap after t=0 is longer than `stall_ms`. |
| `sync_log` | The list holds one `{ text, cueAt, runAt, n, firstOn }` object per `data-sync` element that matched, copied from `window.__decktalk.syncLog`. |
| `lead_method` | The field says how `measure` found the lead-in. A value beginning `NO COVER` is a guess. |
| `warnings` | The list holds `window.__decktalk.warnings`, read from the page after the recording, such as an unknown cue id or a KaTeX that never loaded. |
| `page_errors` | The list holds one line for every uncaught exception the page threw while it was recorded, plus one entry when the page has no `window.__decktalk.catalog` or an empty one. `check` reports `PAGE ERROR` for a sidecar with any entry, and `build` stops. |

## `build/out/`

| File | Meaning |
|---|---|
| `NN-section.mp4` | The file holds one section cut to its span, at the project's frame size, with video only. |
| `<name>.mp4` | The file is the video, with a chapter per section muxed in. |
| `<name>-YYYYMMDD-HHMM.mp4` | The file is a timestamped copy of the same video. |
| `<name>.srt`, `<name>.vtt` | The files hold captions from the word timestamps, absolute in the mp4, with the script's punctuation and case. A caption holds at most two lines of 42 characters, ends at a sentence, a pause longer than 1.5 seconds, or seven seconds, and never spans a section. |
| `<name>.chapters.txt` | The file is an ffmetadata file with one `[CHAPTER]` per section, titled from `decktalk.toml`, which is what the mp4 carries. |
| `slates/NN-slate.png` | The files are rendered slates for clip sections whose file is missing. |

```text build/out/my-lesson.srt
1
00:00:00,700 --> 00:00:04,044
The curve rises, then the number lands.

2
00:00:04,044 --> 00:00:05,956
You just watched DeckTalk.
```

```text build/out/my-lesson.chapters.txt
;FFMETADATA1

[CHAPTER]
TIMEBASE=1/1000
START=0
END=18360
title=Open
```

## `build/shots/`

`step-<id>.png` for each step and `step-<id>-cue-<cue>.png` for a step frozen at one of
its cues, both in a subdirectory named after the page when the project has several pages,
and `section-NN-at-<S>s.png` for each frame taken from a playing section.
