---
title: Configuration
description: Defaults, decktalk.toml, and environment variables.
---

Settings come from three layers, and each layer overrides the one before it.

1. The defaults live in `decktalk.config`, with one dataclass per concern.
2. Tables of the same names in the project's `decktalk.toml` override the defaults. For example, `[video] preset = "veryfast"` changes the x264 preset for that project.
3. Environment variables named `DECKTALK_<SECTION>_<FIELD>` override the file. For example, `DECKTALK_VIDEO_PRESET=veryfast` changes the preset for one shell.

A few CLI flags, namely `--preset`, `--crf`, `--settle`, and `--model`, override all three
for a single run.

Content that changes per presentation lives in the same file, but as the document rather
than as tuning. That covers sections, voice, mix levels, and soundscape prompts. The
project file page describes it. Secrets live only in `.env`.
