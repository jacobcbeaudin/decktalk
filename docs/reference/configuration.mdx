title: Configuration

Three layers, lowest to highest precedence:

1. Defaults in `decktalk.config`, one dataclass per concern.
2. Tables of the same names in the project's `decktalk.toml`, for example `[video] preset = "veryfast"`.
3. Environment variables `DECKTALK_<SECTION>_<FIELD>`, for example `DECKTALK_VIDEO_PRESET=veryfast`.

A few CLI flags (`--preset`, `--crf`, `--settle`, `--model`) override for one run.

Per-presentation content (sections, voice, mix levels, soundscape prompts) lives in the
same file as the document rather than as tuning: see [the project file](/concepts/project-file).
Secrets live only in `.env`.
