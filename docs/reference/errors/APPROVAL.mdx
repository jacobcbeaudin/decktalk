A step was not approved, by a flag or by a person at a terminal: a spend, a spend --max-cost refuses or cannot price, an init into a directory that holds files, a password install asks for, or an untrusted page in a run that may spend.

A command that ends this way exits 2. The JSON object carries `error.code` of
`APPROVAL` and one sentence in `error.message`. `error.hint` carries the next step when
DeckTalk knows one, and is null when it does not.

## What to do

Pass `--spend` to approve a spend, with `--max-cost N` beside it to refuse a run whose most is over N US dollars, or `--no-spend` to buy nothing. For any other step, follow the hint, which names the command that approves it.

Troubleshooting says more under [A refused command line](/help/troubleshooting#a-refused-command-line).
