The `decktalk` command runs one stage, the whole pipeline, or one reading of the project or the
machine. Every command prints one flat JSON object with `--json`, carrying its own fields beside
`schema`, `ok`, `findings` and `error`, and the two declared fields `run` and `written` on the
commands that open a run or write a file.

## Global options

These work with every command, before or after the command name.

| Option | Meaning |
|---|---|
| `-p`, `--project` `DIR` | The project directory. Default: DECKTALK_PROJECT, else the current directory. |
| `--json` | Print one JSON object on stdout and nothing else there. |
| `--events` | Print one JSON line per progress event on stderr. |
| `--color` `WHEN` | auto, always or never. Default: auto. |
| `--no-input` | Never prompt. Take the safe default, or refuse and name the flag that would have answered. |
| `-v`, `--verbose` | Debug lines on stderr, and the traceback of a bug. |
| `-q`, `--quiet` | Warnings and errors only on stderr. |
| `--version` | Print the version and exit. |

## Exit codes

| Exit | Meaning |
|---|---|
| 0 | The command ran and found nothing. |
| 1 | The command ran and found something at or above the threshold --fail-on set. |
| 2 | The command line was refused, which is USAGE or APPROVAL. |
| 3 | The command could not run, which is every other error code. |
| 130 | The caller stopped the run. |

## Error codes

An error means DeckTalk could not run, so nothing was judged. A finding is the other thing
entirely, which is a judgement about a film that did get made.

| Code | Exit | Meaning |
|---|---|---|
| `INPUT` | 3 | A file the author writes is missing, unreadable or malformed. |
| `NOT_BUILT` | 3 | A file a stage needs was never built. |
| `PROVIDER` | 3 | The voice could not be reached, refused the request, or failed it. |
| `TOOL` | 3 | ffmpeg or Chromium is missing, or one of them failed. |
| `LOCKED` | 3 | Another writer holds this project's build directory. |
| `APPROVAL` | 2 | A spend needed an approval that no flag and no terminal gave. |
| `CANCELLED` | 130 | The caller stopped the run. |
| `USAGE` | 2 | The command line was refused, and a retry as written fails again. |
| `INTERNAL` | 3 | A bug in DeckTalk, with a traceback under -v. |

## Finding codes

A finding carries its code, its sentence, its certainty and often a fix an agent can apply.
`--allow CODE` carries on past one, and `--fail-on` decides which of them fails a run.

| Code | Certainty | Meaning |
|---|---|---|
| `PAGE_UNKNOWN_ATTR` | certain | An element carries a data attribute the contract does not declare, so nothing reads it. |
| `PAGE_BAD_VALUE` | certain | An attribute's value is outside the range the contract publishes for it. |
| `PAGE_MOMENT_UNKNOWN` | certain | A slide names a moment that no element on it declares, so nothing happens when it comes. |
| `PAGE_MOMENT_ORDER` | certain | An element's moments are declared out of the order they play, which is in, back, front and out. |
| `PAGE_CUE_UNKNOWN` | certain | A moment names a cue the runtime cannot qualify against the slide it sits on. |
| `PAGE_NO_OWNER` | certain | An element declares a moment and no slide owns it, so nothing decides when it plays. |
| `PAGE_SCENE_EMPTY` | certain | A slide renders no element at all, so its section would play an empty picture. |
| `PAGE_SLIDE_NO_ID` | certain | A slide template carries no id, so no cue and no section can name it. |
| `PAGE_SLIDE_DOUBLED` | certain | Two slide templates carry the same id, so a cue that names it is ambiguous. |
| `PAGE_SLIDE_UNUSED` | certain | No section plays this slide, so nothing on it reaches the film. |
| `PAGE_TEMPLATE_IGNORED` | certain | A template sits outside every slide, so the runtime never instantiates it. |
| `PAGE_WORDS_NOT_FOUND` | certain | An element syncs to words the transcript does not hold, so word timing cannot start. |
| `PAGE_KATEX_MISSING` | certain | The page asks for KaTeX and the library is not loaded, so every formula shows its source. |
| `PAGE_KATEX_ERROR` | certain | KaTeX refused a formula, so that element shows an error where the maths should be. |
| `PAGE_FREEZE_CUE_UNKNOWN` | certain | A freeze was asked for a cue the slide does not declare, so no frame could be made. |
| `PAGE_RENDER_THREW` | certain | A slide's render threw, so the slide is not on screen. |
| `PAGE_ENTER_THREW` | certain | A slide's enter threw, so its opening moment never ran. |
| `PAGE_SLIDE_HANDLER_THREW` | certain | A slide's own moment handler threw, so that moment did not play. |
| `PAGE_HANDLER_THREW` | certain | A moment handler threw, so the change it was to make never happened. |
| `PAGE_WAIT_REJECTED` | certain | A wait the page declared was rejected, so the runtime carried on without what it waited for. |
| `PAGE_WAIT_UNSETTLED` | certain | A wait the page declared never settled inside its budget, so the runtime carried on without it. |
| `PAGE_CLASS_UNDESCRIBED` | certain | An element changes class with no description, so the transcript cannot say what changed. |
| `PAGE_CLASS_NOT_REDUCED` | certain | A class change declares no reduced form, so a reduced render would animate anyway. |
| `PAGE_SWAP_AMBIGUOUS` | certain | Two elements claim the same swap, so the runtime cannot tell which one leaves. |
| `PAGE_PREVIEW_AMBIGUOUS` | certain | Two elements claim the same preview, so preview mode cannot choose between them. |
| `PAGE_APPEAR_TOO_LONG` | certain | An entrance runs longer than the span a cue can still be measured under. |
| `PAGE_STAGGER_EMPTY` | certain | An element staggers its children and has none, so the stagger plays nothing. |
| `PAGE_MOTION_OVERRUN` | certain | A motion span runs past the measurable ceiling, so the cue it carries cannot be verified. |
| `PAGE_STAGGER_OVERRUN` | certain | A staggered entrance totals past the measurable ceiling, and the arithmetic that says so is exact. |
| `PAGE_WORD_LATE` | uncertain | A word-synced element lands after the word it is synced to. |
| `PAGE_THIN_DRAW` | uncertain | A frozen slide draws less of the picture than a change must cross to be seen. |
| `PAGE_NO_DESCRIPTION` | certain | An element changes the picture and describes nothing, so the transcript loses the change. |
| `PAGE_SWAP_APART` | uncertain | A swap's two halves land far enough apart that a viewer sees the gap between them. |
| `PAGE_STALLED` | certain | The picture held still for longer than a recorded section ever should. |
| `PAGE_BLACK` | certain | A recorded frame is black, so the film shows nothing at that moment. |
| `PAGE_TRUNCATED` | certain | A recording stopped before its section's clock ran out, so the film is short of picture. |
| `PAGE_CDN_ASSET` | certain | The page loads an asset from a network origin, so the film depends on somebody else's server. |
| `CUE_MISSING` | certain | The page declares a moment that cues.json does not list, so nothing gives it a second. |
| `CUE_UNKNOWN` | certain | cues.json lists a cue no page declares, so nothing plays it. |
| `CUE_UNRESOLVED` | certain | The cue's phrase is not spoken in its section, so there is no second to place it at. |
| `CUE_OFF` | certain | The change lands further from its word than the offset limit allows. |
| `CUE_NO_ONSET` | uncertain | The cue resolved with no measured onset, so its second is the section's start and not its word's. |
| `CUE_NO_CHANGE` | certain | Nothing in the picture changed at the cue's second, so the reveal never happened. |
| `CUE_THIN_CHANGE` | uncertain | Less of the picture changed at the cue than a visible reveal must cross. |
| `CUE_OVERLAP` | uncertain | Two cues resolve close enough together that a viewer cannot tell them apart. |
| `TAKE_PLACEHOLDER` | certain | The script still holds an open placeholder, so a voiced run would read it out. |
| `TAKE_SPOKEN_SYMBOL` | uncertain | The script holds a symbol the voice reads as its name rather than as the thing it means. |
| `CUT_SPEECH` | certain | Speech is still sounding at a section cut, so the film slices a word in two. |
| `CUT_POP` | certain | The picture steps at a section cut, so the film pops on the seam. |
| `MIX_LOUDNESS` | uncertain | The mixed film misses the loudness it was mastered to. |
| `FILE_MISSING` | certain | A file the project names is not on disk. |

## Commands

### Set up this machine

#### `decktalk init`

Create a project with a deck that already builds.

```text
decktalk init [OPTIONS] DIR
```

It answers with the `init` result: `decktalk schema init`.

| Option | Meaning |
|---|---|
| `--name` `NAME` | The project's name. |
| `--example` `NAME` | The packaged example to write. |
| `--no-skills` | Leave the packaged skills out. |
| `--defaults` | Take every default and ask nothing. |
| `--overwrite` | Write into a directory that already holds files. |

#### `decktalk install`

Fetch Chromium and ffmpeg before a build needs them.

```text
decktalk install [OPTIONS]
```

It answers with the `install` result: `decktalk schema install`.

#### `decktalk doctor`

Report what is installed and what a run would use.

```text
decktalk doctor [OPTIONS]
```

It answers with the `doctor` result: `decktalk schema doctor`.

| Option | Meaning |
|---|---|
| `--measure` | Measure this host's presentation bias, which drives a browser. |
| `--fix`, `--no-fix` | Apply every safe fix, or apply none. An unsafe fix is printed either way and never applied. |
| `--fail-on` `WHEN` | certain fails on a certain finding, any fails on any finding, never fails on none. Default certain. |
| `--allow` `CODE` | Carry on past this finding code. Repeats. |

## The contract

`decktalk schema` prints the whole instruction set. `decktalk schema NAME` takes `apply`, `assemble`, `build`, `check`, `clip`, `config-explain`, `config-get`, `config-list`, `config-set`, `config-unset`, `cue`, `doctor`, `error`, `init`, `install`, `narrate`, `record`, `serve`, `soundscape`, `status`, `storyboard`, `verify`, `words`, `error`, `event`, `finding`, `page`, `project`, `settings`.
