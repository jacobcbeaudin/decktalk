---
title: CLI
description: Every command, and what it produces.
---

Every project command takes `--project DIR`, or `-p DIR`, and defaults to the current
directory. Each one reads `.env` from the project and never prints a key. The `-v` flag
shows every ffmpeg command line, and `-q` shows warnings only.

| Command | What it does |
|---|---|
| `decktalk init DIR` | Scaffolds a project with a working example deck. |
| `decktalk setup` | Fetches headless Chromium and ffmpeg. |
| `decktalk doctor` | Reports what is installed. |
| `decktalk narrate [--dry-run] [--silent] [--only N] [--force] [--allow-placeholders] [--model M]` | Turns the script into per-section audio with word timestamps, then builds the continuous track and `timeline.json`. It caches each section by text. |
| `decktalk beats` | Resolves every cue phrase to a second. It reports any phrase it cannot find and exits with status 1 if there is one. |
| `decktalk soundscape [--dry-run] [--only NAME]` | Generates the ambience, the sound effects, and the underscore from the prompts in `decktalk.toml`. |
| `decktalk record [--only N] [--seconds S] [--settle S] [--no-beats]` | Records the pages with headless Chromium. |
| `decktalk measure [--only N]` | Finds narration t=0 in each recording from the magenta marker. |
| `decktalk check [--only N] [--strict]` | Flags black or truncated recordings. |
| `decktalk assemble [--preset P] [--crf N] [--nomix] [--no-loudnorm] [--strict]` | Cuts, concatenates, mixes, normalizes, and publishes the film. |
| `decktalk verify [SEC:CUE ...]` | Confirms that every section opens on a real frame and that the picture changes at each named cue. |
| `decktalk shots [--page F] [--step ID] [--section N --at S]` | Writes one PNG per step, or frames from a section while it plays with its real cues. |
| `decktalk build [--silent] [--force] [--only N] [--nomix] [--no-loudnorm] [--strict] [--allow-unresolved] [--preset P] [--crf N]` | Runs the whole pipeline in order. |
| `decktalk status` | Prints the timeline and what is built. |
| `decktalk runtime` | Copies the packaged `decktalk-runtime.js` over the project's copy after an upgrade. |

## Build artifacts

| File | What it holds |
|---|---|
| `build/audio/NN-slug.mp3` and `.words.json` | One pair per narrated section. The words file holds `[{word, start, end}]`. |
| `build/audio/narration.mp3` and `timeline.json` | The continuous track, and each section's absolute span and words within it. |
| `build/audio/beats.json` | `{"NN": "cue@seconds,..."}`, with seconds relative to the section start. |
| `build/rec/NN-scene.webm` and `.json` | The recording and its sidecar, which records the settle, the lead-in, and the method. |
| `build/out/NN-section.mp4` | Each section cut to its span. |
| `build/out/<name>.mp4` | The film, plus a timestamped copy. |
| `build/shots/` | Review screenshots. |
