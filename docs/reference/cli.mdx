The `decktalk` command runs each build stage on its own, or all seven stages with `decktalk build`.
This page lists every command with its options, the files it reads and writes, its output, and its
exit codes.

## Global options

These options work with every command.

```text
decktalk [-h] [--version] [--project PROJECT] [-v] [-q] <command> ...
```

| Option | Default | Meaning |
|---|---|---|
| `-p PROJECT`, `--project PROJECT` | `$DECKTALK_PROJECT`, then the current directory | Project directory. `init`, `setup`, and `doctor` ignore it. |
| `-v`, `--verbose` | off | Logs debug lines, including every ffmpeg command line. |
| `-q`, `--quiet` | off | Logs warnings only. |
| `--version` | none | Prints `decktalk <version>` and exits 0. |
| `-h`, `--help` | none | Prints the usage and exits 0. |

- `-v` and `-q` go before or after the command name.
- `-p` goes before the command name, or after it on every command except `init`, `setup`, and `doctor`.
- Every other option goes after the command name.
- A repeatable option takes one value each time. Write `--only 3 --only 5`, not `--only 3,5`.
- Logs go to stderr. Tables and JSON go to stdout.
- A command reads each key from the environment first, then from `.env` in the project.
- DeckTalk never prints a key.

## Environment variables

| Variable | Default | Meaning |
|---|---|---|
| `DECKTALK_PROJECT` | none | Default project directory. |
| `DECKTALK_CONFIG` | per platform, below | Per-machine settings file. |
| `DECKTALK_CACHE_DIR` | per platform, below | KaTeX cache. Playwright keeps Chromium in its own cache. |
| `DECKTALK_FFMPEG`, `DECKTALK_FFPROBE` | none | Paths to your own binaries. Set both. They win over `static-ffmpeg` and `PATH`. |
| `DECKTALK_<TABLE>_<FIELD>` | none | One tuning field, such as `DECKTALK_VIDEO_PRESET=veryfast`. |
| `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID` | none | Speech provider secrets. Also read from `.env`. |

| Default path | Linux | macOS | Windows |
|---|---|---|---|
| `DECKTALK_CONFIG` | `$XDG_CONFIG_HOME/decktalk/decktalk.toml`, else `~/.config/decktalk/decktalk.toml` | `~/Library/Application Support/decktalk/decktalk.toml` | `%APPDATA%\decktalk\decktalk.toml` |
| `DECKTALK_CACHE_DIR` | `$XDG_CACHE_HOME/decktalk`, else `~/.cache/decktalk` | `~/Library/Caches/decktalk` | `%LOCALAPPDATA%\decktalk` |

Note: a key value that starts with `<` counts as unset, so the placeholders in `.env.example` never
reach the provider. [Configuration](/reference/configuration) lists every tuning field.

## Setup commands

### `decktalk setup`

Downloads Chromium, ffmpeg, and KaTeX, one time per machine.

```text
decktalk setup [-h] [-v] [-q]
```

**Reads** nothing. **Writes** Chromium to Playwright's cache, ffmpeg and ffprobe into the Python
environment through `static-ffmpeg`, and KaTeX to the DeckTalk cache.

- On Linux, `setup` also installs Chromium's system libraries. [What setup downloads](/requirements#what-setup-downloads) lists the paths and the permissions it needs.
- A download that already exists is not downloaded again.
- If the KaTeX download fails, `setup` warns and still exits 0. Pages then load KaTeX from a CDN.

| Exit | When |
|---|---|
| 0 | Every download finished or was already cached. |
| 1 | `playwright install failed. See the output above.`, or another error. |

### `decktalk doctor`

Reports each tool that DeckTalk needs and where it found the tool.

```text
decktalk doctor [-h] [-v] [-q] [--json] [--strict] [--no-fail]
```

| Option | Default | Meaning |
|---|---|---|
| `--json`, `--strict`, `--no-fail` | off | See [Output and exit flags](#output-and-exit-flags). |

**Reads** Playwright's Chromium (it launches it), the ffmpeg locations, the per-machine config path,
and the KaTeX cache. **Writes** nothing. `doctor` never downloads anything.

| Row | Detail when `ok` | When not `ok` |
|---|---|---|
| `python` | Version and absolute interpreter path. | Always `ok`. |
| `chromium` | Chromium version. | `MISSING`. Chromium does not launch, or the `playwright` package is missing. |
| `ffmpeg` | Absolute path. | `MISSING`. No binaries from `DECKTALK_FFMPEG`, `static-ffmpeg`, or `PATH`. |
| `ffprobe` | Absolute path. | Not printed when `ffmpeg` is `MISSING`. |
| `config` | The file path, or `none (optional, at <path>)`. | Always `ok`. |
| `katex` | Cache directory. | `warning`. The cache is empty, so pages load KaTeX from a CDN. |

Note: a `MISSING` row is a certain finding. A `warning` row is an uncertain finding, so it exits 1
only with `--strict`. When ffmpeg is not found, `doctor` prints one `ffmpeg MISSING` row and no
`ffprobe` row. In the JSON, a `warning` row has `"ok": false` and `"required": false`.

| Exit | When |
|---|---|
| 0 | No row is `MISSING`. A `warning` row passes without `--strict`. |
| 1 | A row is `MISSING`, or a row is `warning` and `--strict` is on. |

### `decktalk init`

Writes the scaffold into a new directory.

```text
decktalk init [-h] [-v] [-q] [--name NAME] [--force] dir
```

| Option | Default | Meaning |
|---|---|---|
| `dir` | required | Directory to write. It can exist if it is empty. |
| `--name NAME` | the directory name | Project name. Starts with a letter or digit, then letters, digits, dots, dashes, or underscores. |
| `--force` | off | Writes into a directory that is not empty. Overwrites files that the scaffold also has. |

**Reads** the packaged template and the KaTeX cache. **Writes** `decktalk.toml`, `script.md`,
`cues.json`, `.gitignore`, `.env.example`, `media/markers.json`, and `deck/`. `deck/` holds
`index.html`, `lesson.html`, the fonts, `decktalk-runtime.js`, and `katex/` when KaTeX is cached.

If KaTeX is not cached, `init` warns and writes CDN tags into `deck/index.html`. The warning starts
with `KaTeX is not cached, so the pages in deck/ load it from a CDN.`

| Exit | When |
|---|---|
| 0 | The scaffold is written. |
| 1 | The name is not valid, or the directory is not empty and `--force` is off. |

{/* sample: decktalk init my-lesson, KaTeX cached (A-qs-01) */}

```text
created ~/my-lesson
  decktalk.toml  the plan: sections -> pages or clips, voice, mix, soundscape
  script.md      the narration (## N. sections)
  cues.json      which spoken phrase each visual lands on
  deck/          index.html, lesson.html, decktalk-runtime.js (open a page for its scene index)
  media/         your clips, b-roll, markers.json
next: cp .env.example .env  (ELEVENLABS_API_KEY, ELEVENLABS_VOICE_ID), then `decktalk build`
      or `decktalk build --silent` to render with placeholder narration and no API key
```

### `decktalk runtime`

Copies the packaged page runtime into the project.

```text
decktalk runtime [-h] [--project PROJECT] [-v] [-q]
```

**Reads** nothing but the project tree. **Writes** every `decktalk-runtime.js` under the project, or
`deck/decktalk-runtime.js` when the project has none. Run it after you upgrade DeckTalk.

| Exit | When |
|---|---|
| 0 | Every copy is written. |
| 1 | The project does not load. |

{/* sample: decktalk runtime in a fresh scaffold (F-r2-05) */}

```text
updated ~/my-lesson/deck/decktalk-runtime.js
```

## `decktalk build`

Runs all seven stages in order and prints each stage's table.

```text
decktalk build [-h] [--project PROJECT] [-v] [-q] [--silent] [--force]
               [--only ONLY] [--nomix] [--no-loudnorm] [--strict]
               [--allow-unresolved] [--allow-unknown] [--preset PRESET]
               [--crf CRF]
```

| Option | Default | Meaning |
|---|---|---|
| `--silent` | off | Uses estimated word times and writes a click track. Needs no key. |
| `--force` | off | Voices every section again. Spends credits on every section. |
| `--only ONLY` | every section | Records, measures, and checks only these sections. Repeatable. |
| `--allow-unresolved` | off | Continues when a cue phrase is not found. |
| `--allow-unknown` | off | Continues when a cue id is not in its page. |
| `--strict` | off | Fails on a missing recording, or a missing clip without `optional = true`. In a voiced build, also fails on a loudness miss. |
| `--nomix` | off | Mixes narration and clip audio only. |
| `--no-loudnorm` | off | Skips the loudness pass. |
| `--preset PRESET` | `[video] preset` | x264 preset for this run. |
| `--crf CRF` | `[video] crf` | x264 quality for this run. |

Note: with `--only`, `narrate` still runs on every section and `assemble` still uses every section.
Recordings of other sections stay as they are. A silent build after a voiced build empties the
narration cache, as [A silent build and a voiced build](/guides/rebuild-one-section#a-silent-build-and-a-voiced-build)
explains.

**Reads** and **writes** what each stage reads and writes, below.

| Stage | `build` exits 1 when | Override |
|---|---|---|
| `beats` | A cue phrase is not found. The build stops after the beats table. | `--allow-unresolved` |
| `beats` | A cue id is not in its page. The build stops after the beats table. | `--allow-unknown` |
| `check` | A page threw an error or has no catalog (`PAGE ERROR`). The build stops after the check table. | none |
| `assemble` | With `--strict`, a recording is missing, or a clip is missing from a section without `optional = true`. | Set `optional = true`, or leave out `--strict`. |
| `verify` | A section starts black (`BLACK`), or speech is still sounding at a cut (`SPEECH AT CUT`). | none |
| any | A stage raises an error. | none |

`build` does not measure cues. It exits 0 on `TRUNCATED`, `STALLED`, `NO COVER`, `BLACK?`, and
`KATEX?`. To gate a script on the whole video, run `check` and `verify` after the build, as
[Build in CI and offline](/guides/ci-and-offline) shows.

These are the last lines of a silent build of the scaffold.

## Stages

`build` runs these seven commands in this order. Each one also runs on its own.

### `decktalk narrate`

Voices the script and writes each section's audio and word times.

```text
decktalk narrate [-h] [--project PROJECT] [-v] [-q] [--only ONLY]
                 [--force] [--allow-placeholders] [--dry-run]
                 [--silent] [--model MODEL]
```

| Option | Default | Meaning |
|---|---|---|
| `--only ONLY` | every spoken section | Voices only these sections. Repeatable. |
| `--force` | off | Ignores the narration cache. Spends credits on every section it voices. |
| `--allow-placeholders` | off | Voices a section that still has a `[CAPS]` placeholder. |
| `--dry-run` | off | Prints each section's text, the voice settings, and the table. Sends nothing. |
| `--silent` | off | Writes a click track with estimated word times. Needs no key. |
| `--model MODEL` | `[voice] model`, then `[narration] model` | Speech model id for this run. |

**Reads** `script.md`, `decktalk.toml`, and `.env`. `--silent` and `--dry-run` need no key.
**Writes** `build/audio/NN-slug.mp3`, `NN-slug.words.json`, `manifest.json`, `narration.mp3`, and
`timeline.json`. `--dry-run` writes nothing.

- `narrate` never voices a clip section.
- `narrate` caches each section by provider, voice id, model, output format, voice settings, and text.
- `--only` rebuilds `narration.mp3` and `timeline.json` from every voiced section, not only the named ones.
- `--only` with no spoken section fails, for example `no spoken sections match [5]; spoken sections are [1, 2, 3, 4, 6, 8, 9]`.
- A placeholder fails a voiced run with `unfilled placeholders [...] in the script`.

The first table gives each section's word count, estimate (`est`), time budget (`target`), and audio
length (`actual`). The second table is the timeline in `narration.mp3`.
[script.md](/reference/script-md#length) gives the estimate formulas.

| Exit | When |
|---|---|
| 0 | Every target section is voiced or cached. |
| 1 | An error: no script, no sections, a section with no `[[section]]`, a placeholder, a missing key, or a provider error. |

### `decktalk beats`

Resolves each cue phrase to a cue time and writes `beats.json`.

```text
decktalk beats [-h] [--project PROJECT] [-v] [-q] [--json] [--strict]
               [--no-fail] [--allow-unknown]
```

| Option | Default | Meaning |
|---|---|---|
| `--allow-unknown` | off | Does not count a cue id that is missing from its page. The table still notes it. |
| `--json`, `--strict`, `--no-fail` | off | See [Output and exit flags](#output-and-exit-flags). |

**Reads** `manifest.json`, the words files, `cues.json`, and each page. **Writes** `beats.json` and
`beats.anchors.json`, even when it exits 1.

`beats` looks for each cue id in its page as a quoted literal, in single quotes, double quotes, or
backticks. A `data-cue` value, a key of a step's `cues` object, and a handler key all count.
[Cues](/concepts/cues#matching-rules) gives the phrase matching rules.

The table columns are `sec`, `speech` (the speech end in seconds), `need` (`min_seconds`), and
`cues` (each `id@seconds`). A note line starts with `!`.

| Note | Finding | Exit |
|---|---|---|
| `<cue>: phrase not found: '<phrase>'` | certain, `UNRESOLVED` | 1 |
| `<cue>: no words (estimated manifest)` or `(missing words file)` | certain, `UNRESOLVED` | 1 |
| `<cue>: not in <page>` | certain, `UNKNOWN`. None with `--allow-unknown`. | 1 |
| `speech <S>s is <D>s shorter than the visuals need` | uncertain | 1 with `--strict` |
| `<cue>: <T>s is past the end of the audio (<D>s)` | none | 0 |

Note: a clip section with cues prints `--` and `(no narration (clip section, or not rendered))`.

### `decktalk record`

Records each page section in headless Chromium to a webm.

```text
decktalk record [-h] [--project PROJECT] [-v] [-q] [--only ONLY]
                [--seconds SECONDS] [--settle SETTLE] [--no-beats]
```

| Option | Default | Meaning |
|---|---|---|
| `--only ONLY` | every page section | Records only these sections. Repeatable. |
| `--seconds SECONDS` | section span plus `extra_seconds` | Records every section for this long. Works with no timeline. |
| `--settle SETTLE` | `[record] settle_seconds` (0.5) | Least seconds after the page is ready before narration t=0. The recorder also waits for `[record] min_lead_seconds`. |
| `--no-beats` | off | Plays the page in autoplay instead of passing `?beats=`. |

**Reads** `timeline.json` (not with `--seconds`), `beats.json` (not with `--no-beats`), and the pages.
**Writes** `build/rec/NN-scene.webm` and its sidecar `NN-scene.json`.

- `record` prints no table. It logs one `[rec ]` line per section and every page warning as `[page]`.
- `record` skips a page section that has no span and logs `no narration span yet; skipped`.
- If the page stalls after narration t=0 for longer than `[align] stall_ms` (150), `record` records the section again.
- `record` tries again up to `[record] retries` (2) times.

| Exit | When |
|---|---|
| 0 | Every matched section is recorded. |
| 1 | No timeline and no `--seconds`, a page file is missing, or no page section matches. |

### `decktalk measure`

Finds narration t=0 in each recording and writes it to the sidecar.

```text
decktalk measure [-h] [--project PROJECT] [-v] [-q] [--only ONLY]
```

| Option | Default | Meaning |
|---|---|---|
| `--only ONLY` | every recording | Measures only these sections. Repeatable. |

**Reads** each webm and its sidecar. **Writes** `lead_in_seconds` and `lead_method` into the sidecar.

`measure` scans the first `[align] scan_seconds` (4.0) of the recording and finds the last magenta
frame. Narration t=0 is one frame after it. The table columns are `trim` (t=0 in the webm),
`wall` (the recorder's own clock estimate), and `method`.

| Method | Meaning |
|---|---|
| `cover (N magenta frames)` | Found the cover. |
| `NO COVER: first paint + settle` | No cover. The first painted frame plus `settle_seconds`. |
| `NO COVER: fallback guess + settle` | No painted frame. `fallback_first_paint_seconds` (1.1) plus `settle_seconds`. |
| `no frames read; fallback` | ffmpeg read no frames. The same fallback. |

| Exit | When |
|---|---|
| 0 | Every recording is measured. |
| 1 | No recordings exist. |

### `decktalk check`

Checks each recording's length, brightness, and recorder warnings.

```text
decktalk check [-h] [--project PROJECT] [-v] [-q] [--json] [--strict]
               [--no-fail] [--only ONLY]
```

| Option | Default | Meaning |
|---|---|---|
| `--only ONLY` | every recording | Checks only these sections. Repeatable. |
| `--json`, `--strict`, `--no-fail` | off | See [Output and exit flags](#output-and-exit-flags). |

**Reads** each webm and its sidecar. **Writes** nothing.

Each row describes one recording.

| Column | Meaning |
|---|---|
| `webm_s` | Recorded seconds. |
| `want_s` | Requested seconds. |
| `Y10`, `Y50`, `Y90` | Average luma at 10, 50, and 90 percent of the recording. |
| `MAX50` | Brightest luma at the middle of the recording. |
| `verdict` | One or more verdicts from the table below. |

| Verdict | Finding | Meaning |
|---|---|---|
| `ok` | none | No finding. |
| `PAGE ERROR` | certain | The page threw an uncaught error, or has no `window.__decktalk.catalog`. `build` stops. |
| `STALLED <ms>ms` | certain | A frame gap after narration t=0 exceeded `[align] stall_ms` (150) on the last try. |
| `TRUNCATED` | certain | Shorter than requested by more than `[align] truncated_slack_seconds` (0.5). |
| `NO COVER` | certain | `measure` found no cover. The trim is a guess. |
| `BLACK?` | uncertain | `MAX50` is below `[align] black_ymax` (40). |
| `KATEX?` | uncertain | A page warning contains "katex" or "data-tex", in any case. |

Note: one row can show several verdicts, separated by spaces. The JSON lists them in `verdicts` and
puts the stall length in `stall_ms`.

| Exit | When |
|---|---|
| 0 | No certain verdict, and no uncertain verdict with `--strict`. |
| 1 | A certain verdict, an uncertain verdict with `--strict`, or no recordings. |

### `decktalk assemble`

Cuts, mixes, and writes the final video with its captions and chapters.

```text
decktalk assemble [-h] [--project PROJECT] [-v] [-q] [--nomix]
                  [--no-loudnorm] [--strict] [--preset PRESET]
                  [--crf CRF]
```

| Option | Default | Meaning |
|---|---|---|
| `--nomix` | off | Mixes narration and clip audio only. No underscore, ambience bed, or sound effects. |
| `--no-loudnorm` | off | Skips the loudness pass. |
| `--strict` | off | Fails on a missing recording, or a missing clip without `optional = true`. In a voiced build, also fails on a loudness miss. |
| `--preset PRESET` | `[video] preset` | x264 preset for this run. `veryfast` is for drafts. |
| `--crf CRF` | `[video] crf` | x264 quality for this run. |

**Reads** `timeline.json`, `manifest.json`, `beats.json`, the recordings and sidecars, the clips, the
markers file, the underscore, the ambience bed, and the sound effects. **Writes**
`build/out/NN-section.mp4`, `<name>.mp4`, a copy named `<name>-YYYYMMDD-HHMM.mp4`, `<name>.srt`,
`<name>.vtt`, `<name>.chapters.txt`, and `build/out/slates/`.

- Without `--strict`, a missing clip plays a titled slate for `slate_seconds`, and a missing recording plays black.
- A missing underscore, ambience bed, markers file, or sound effect logs a warning and plays without it.
- A silent build skips the loudness pass, so `--strict` has no loudness to fail on.
- `assemble` prints the final path and length on stdout.

| Exit | When |
|---|---|
| 0 | The final video is written. |
| 1 | No timeline, a page section with no span, or a `--strict` failure. |

### `decktalk verify`

Checks section starts, cuts, and cues in the final video.

```text
decktalk verify [-h] [--project PROJECT] [-v] [-q] [--json] [--strict]
                [--no-fail] [--cue SECTION:CUE] [--only ONLY]
                [SECTION:CUE ...]
```

| Option | Default | Meaning |
|---|---|---|
| `SECTION:CUE ...` | every cue in `beats.json` | Checks only these cues, such as `8:7.1checked`. |
| `--cue SECTION:CUE` | none | Adds one cue after the positional cues. Repeatable. |
| `--only ONLY` | every section | Keeps only the cues of these sections. Starts and cuts are always checked. Repeatable. |
| `--json`, `--strict`, `--no-fail` | off | See [Output and exit flags](#output-and-exit-flags). |

**Reads** `build/out/NN-section.mp4`, `build/out/<name>.mp4`, `narration.mp3`, `timeline.json`,
`beats.json`, `beats.anchors.json`, `manifest.json`, and `cues.json`. **Writes** nothing.

| Check | Passes when | Keys in `[verify]` |
|---|---|---|
| Start | The brightest luma 0.2 s after the section start is above 60. | `after_dip_seconds`, `visible_ymax` |
| Cut | Narration RMS in the last 0.15 s before the cut is at most -40 dBFS. | `cut_window_seconds`, `cut_max_db` |
| Cue | The change test passes, and the onset is within the offset limit. After a silent build, `a/v` is within the a/v limit too. | [verify reference](/reference/verify#cues) |

- With no cue arguments, `verify` checks every cue in `beats.json`, by section and then by cue time.
- With no cue arguments, `verify` skips a cue that `cues.json` marks `"verify": false`.
- Named cues run in the order given, positional cues first. A named cue runs even when it is opted out.
- `--only` also filters named cues. A named cue outside `--only` gets no row.
- The `verify` stage inside `build` checks starts and cuts, and no cue.

`verify` prints up to three tables: section starts, cuts, and cues. A clip section has a start row but
no cut row. `cut at` is where the section's narration ends in the final video. The cue table gains an
`a/v` column only when at least one measured cue has an `a/v` value. The JSON `silent` key says if
the build was silent. [verify](/reference/verify#cues) defines each column.

| Result | Finding | Meaning |
|---|---|---|
| `ok` | none | The section start shows content. |
| `BLACK` | certain | The brightest luma at the start probe is at most `visible_ymax`. |
| `quiet` | none | The cut has no speech. |
| `SPEECH AT CUT` | certain | Narration RMS before the cut is above `cut_max_db`. |
| `changed` | none | The change test passed, and the onset is within the offset limit or no onset was found. |
| `OFF CUE` | certain | The change test passed, but the offset column or the `a/v` column is past its limit. |
| `NO CHANGE` | certain | The change test failed. |
| `UNRESOLVED` | certain | A named cue is not in `beats.json`. |
| `skipped` | none | Nothing was measured. The reason follows the verdict. |

Note: `OFF CUE` prints no distance. Compare the offset column with 80 ms (`max_offset_frames`) and the
`a/v` column with 120 ms (`max_av_frames`). A measured cue with no click shows `-` in the `a/v` column
and has the JSON reason `NO_CLICK`. `NO_CLICK` is not a failure.

| Reason | Cause | Fix |
|---|---|---|
| `OPTED_OUT` | `cues.json` sets `"verify": false` on the cue. | Name the cue as `SECTION:CUE` to measure it. |
| `REFERENCE_CLAMPED` | No reference frame fits between the floor and one frame before the cue. Usual for a `$start` cue. | Check the reveal by eye with `decktalk shots --step ID --cue CUE`. |
| `SECTION_NOT_ASSEMBLED` | `build/out/NN-section.mp4` does not exist. | Run `decktalk assemble`. |
| `TOO_CLOSE_TO_END` | Every probe falls later than 0.05 s before the section end. | Check the reveal by eye with `decktalk shots --step ID --cue CUE`. |

[verify](/reference/verify#skipped-rows) explains each reason.

| Exit | When |
|---|---|
| 0 | Every start, cut, and measured cue passed. |
| 1 | A certain result, a malformed `SECTION:CUE`, or no assembled video. |

| Mode | Command | Page opens with | Writes |

| Option | Default | Meaning |

**Reads** the pages. With `--section`, also `beats.json` and `timeline.json`. **Writes** the PNGs.

## Output and exit flags

`status`, `beats`, `check`, `verify`, and `doctor` take these three options.

| Option | Default | Meaning |
|---|---|---|
| `--json` | off | Prints one JSON object on stdout instead of the tables. Logs still go to stderr. |
| `--strict` | off | Also exits 1 on an uncertain finding. |
| `--no-fail` | off | Exits 0 on findings. An error still exits 1. |

An uncertain finding is a verdict that ends in `?`. In `beats`, speech shorter than `min_seconds` is
also uncertain. On `assemble` and `build`, `--strict` has a different meaning. It fails on a missing
recording, or a missing clip in a section without `optional = true`.

This shape shows the JSON envelope. The values are types, not a sample.

```jsonc
{
  "command": "verify",
  "version": "<version>",
  "ok": true,
  "findings": { "certain": 0, "uncertain": 0 },
  "verify": { }   // the payload, named after the command
}
```

| Key | Type | Meaning |
|---|---|---|
| `command` | string | Command that ran. |
| `version` | string | DeckTalk version. |
| `ok` | boolean | True when the command exits 0 without `--no-fail`. `--strict` counts. |
| `findings.certain` | integer | Certain findings. Any one exits 1. |
| `findings.uncertain` | integer | Uncertain findings. They exit 1 only with `--strict`. |

| Command | Payload |
|---|---|
| `doctor` | `components`: a list of `{name, ok, detail, required}`, one per row. |
| `status` | The shape under [`decktalk status`](#decktalk-status). |
| `beats` | `estimated`, `beats_file`, `unresolved`, `unknown`, and `sections`. |
| `check` | `recordings`: a list of `{key, file, duration, wanted, y10, y50, y90, max50, verdicts, stall_ms, page_errors}`. |
| `verify` | `final`, `total_seconds`, `silent`, `starts`, `cuts`, and `cues`. |

Note: each `beats` section is `{key, speech_end, min_seconds, skipped, cues, notes}`. Each note is
`{cue, verdict, detail}`, where `verdict` is `UNRESOLVED`, `UNKNOWN`, or `null`. Each `verify` cue row
is `{section, cue, cue_seconds, final_seconds, changed_percent, control_percent, offset_ms, av_ms,
verdict, reason}`. [verify](/reference/verify#json-fields) defines them.

- Every `key` is a two-digit section string such as `"03"`. A `verify` cue row's `section` is an integer.
- A value that does not exist is `null`. Every verdict is the name that the table prints.
- Paths are relative to the project root, with forward slashes. `project.root`, `doctor` details, and paths outside the project stay absolute.
- Only the JSON object goes to stdout, so `decktalk verify --json > verify.json` captures nothing else.

## Exit codes

| Code | Meaning |
|---|---|
| 0 | Success, or `--no-fail` on a command with findings. |
| 1 | An error printed as `error: …` on stderr, or a finding in the table below. |
| 2 | A usage error, such as an unknown option, a missing command, or `shots --cue` without one `--step`. |
| 130 | Interrupted. |

| Command | Exits 1 on (certain) | Exits 1 only with `--strict` (uncertain) |
|---|---|---|
| `doctor` | A `MISSING` row. | A `warning` row, such as `katex`. |
| `beats` | `UNRESOLVED`, and `UNKNOWN` without `--allow-unknown`. | Speech shorter than `min_seconds`. |
| `check` | `PAGE ERROR`, `STALLED`, `TRUNCATED`, `NO COVER`. | `BLACK?`, `KATEX?` |
| `verify` | `BLACK`, `SPEECH AT CUT`, `OFF CUE`, `NO CHANGE`, `UNRESOLVED`. | none |
| `status` | Never. | Never. |
| `build` | See [`decktalk build`](#decktalk-build). | Not used. |
| Every other command | Only an error. | Not used. |

- `--no-fail` makes `doctor`, `beats`, `check`, `verify`, and `status` exit 0 on findings.
- With `--no-fail`, the JSON `ok` key still says if the command passed.
- An error is not a finding. A `DeckTalkError` exits 1, even with `--no-fail`.
- An unexpected exception prints `error: <type>: <message> (add -v for the traceback)` and exits 1.
- With `-v`, an unexpected exception prints its full traceback.
