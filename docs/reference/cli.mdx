The `decktalk` command runs each build stage on its own, or all seven stages with `decktalk build`.
This page lists every command with its options, the files it reads and writes, its output, and its
exit codes.

## Global options

These options work with every command.

```text
decktalk [-h] [--version] [--project PROJECT] [-v] [-q] <command> ...
```

| Option | Default | Meaning |
|---|---|---|
| `-p PROJECT`, `--project PROJECT` | `$DECKTALK_PROJECT`, then the current directory | Project directory. `init`, `install`, and `doctor` ignore it. |
| `-v`, `--verbose` | off | Logs debug lines, including every ffmpeg command line. |
| `-q`, `--quiet` | off | Logs warnings only. |
| `--version` | none | Prints `decktalk <version>` and exits 0. |
| `-h`, `--help` | none | Prints the usage and exits 0. |

- `-v` and `-q` go before or after the command name.
- `-p` goes before the command name, or after it on every command except `init`, `install`, and `doctor`.
- Every other option goes after the command name.
- A repeatable option takes one value each time. Write `--only 3 --only 5`, not `--only 3,5`.
- Logs go to stderr. Tables and JSON go to stdout.
- A command reads each key from the environment first, then from `.env` in the project.
- DeckTalk never prints a key.

## Environment variables

| Variable | Default | Meaning |
|---|---|---|
| `DECKTALK_PROJECT` | none | Default project directory. |
| `DECKTALK_CONFIG` | per platform, below | Per-machine settings file. |
| `DECKTALK_CACHE_DIR` | per platform, below | ffmpeg cache. Playwright keeps Chromium in its own cache. |
| `DECKTALK_FFMPEG`, `DECKTALK_FFPROBE` | none | Paths to your own binaries. Set both. They win over the pinned build and `PATH`. |
| `DECKTALK_<TABLE>_<FIELD>` | none | One tuning field, such as `DECKTALK_VIDEO_PRESET=veryfast`. |
| `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID` | none | Speech provider secrets. Also read from `.env`. |

| Default path | Linux | macOS | Windows |
|---|---|---|---|
| `DECKTALK_CONFIG` | `$XDG_CONFIG_HOME/decktalk/decktalk.toml`, else `~/.config/decktalk/decktalk.toml` | `~/Library/Application Support/decktalk/decktalk.toml` | `%APPDATA%\decktalk\decktalk.toml` |
| `DECKTALK_CACHE_DIR` | `$XDG_CACHE_HOME/decktalk`, else `~/.cache/decktalk` | `~/Library/Caches/decktalk` | `%LOCALAPPDATA%\decktalk` |

Note: a key value that starts with `<` counts as unset, so the placeholders in `.env.example` never
reach the provider. [Configuration](/reference/configuration) lists every tuning field.

## Install commands

### `decktalk install`

Fetches headless Chromium and ffmpeg, one time per machine.

```text
decktalk install [-h] [-v] [-q]
```

**Reads** nothing. **Writes** Chromium to Playwright's cache, and ffmpeg and ffprobe to the DeckTalk
cache. KaTeX ships inside the wheel, so nothing downloads it.

- On Linux, `install` also installs Chromium's system libraries. [What install downloads](/requirements#what-install-downloads) lists the paths and the permissions it needs.
- A download that already exists is not downloaded again.

| Exit | When |
|---|---|
| 0 | Every download finished or was already cached. |
| 1 | `playwright install failed. See the output above.`, or another error. |

{/* sample: decktalk install on a machine that already has both */}

```text
== Chromium (Playwright)
== ffmpeg 8.1.2
   cached  ~/Library/Caches/decktalk/ffmpeg/8.1.2-darwin-arm64/ffmpeg
   ffmpeg  ~/Library/Caches/decktalk/ffmpeg/8.1.2-darwin-arm64/ffmpeg
   ffprobe ~/Library/Caches/decktalk/ffmpeg/8.1.2-darwin-arm64/ffprobe
install complete
```

### `decktalk doctor`

Reports each tool that DeckTalk needs and where it found the tool.

```text
decktalk doctor [-h] [-v] [-q] [--json] [--exit-zero]
```

| Option | Default | Meaning |
|---|---|---|
| `--json`, `--exit-zero` | off | See [Output and exit flags](#output-and-exit-flags). |

**Reads** Playwright's Chromium (it launches it), the ffmpeg locations, the per-machine config path,
and the packaged KaTeX. **Writes** nothing. `doctor` never downloads anything.

| Row | Detail when `ok` | When not `ok` |
|---|---|---|
| `python` | Version and absolute interpreter path. | Always `ok`. |
| `chromium` | Chromium version. | `MISSING`. Chromium does not launch, or the `playwright` package is missing. |
| `ffmpeg` | Absolute path. | `MISSING`. No binaries from `DECKTALK_FFMPEG`, the pinned build, or `PATH`. |
| `ffprobe` | Absolute path. | Not printed when `ffmpeg` is `MISSING`. |
| `config` | The file path, or `none (optional, at <path>)`. | Always `ok`. |
| `katex` | Version and the directory inside the wheel. | `MISSING`. The wheel's KaTeX copy is incomplete, so reinstall DeckTalk. |

Note: every row `doctor` reports names something a build needs, so a `MISSING` row is a certain
finding. When ffmpeg is not found, `doctor` prints one `ffmpeg MISSING` row and no `ffprobe` row.

| Exit | When |
|---|---|
| 0 | No row is `MISSING`. |
| 1 | A row is `MISSING`. |


### `decktalk init`

Writes the scaffold into a new directory.

```text
decktalk init [-h] [-v] [-q] [--name NAME] [--force] dir
```

| Option | Default | Meaning |
|---|---|---|
| `dir` | required | Directory to write. It can exist if it is empty. |
| `--name NAME` | the directory name | Project name. Starts with a letter or digit, then letters, digits, dots, dashes, or underscores. |
| `--force` | off | Writes into a directory that is not empty. Overwrites files that the scaffold also has. |

**Reads** the packaged template and the packaged KaTeX. **Writes** `decktalk.toml`, `script.md`,
`cues.json`, `.gitignore`, `.env.example`, `media/markers.json`, and `deck/`. `deck/` holds
`index.html`, `lesson.html`, the fonts, `decktalk-runtime.js`, and `katex/`.

A project keeps the runtime and the KaTeX copy it was created with. Nothing refreshes them later.

| Exit | When |
|---|---|
| 0 | The scaffold is written. |
| 1 | The name is not valid, or the directory is not empty and `--force` is off. |

{/* sample: decktalk init my-lesson (A-qs-01) */}

```text
created ~/my-lesson
  decktalk.toml  the project file: sections -> pages or clips, voice, mix, soundscape
  script.md      the narration (## N. sections)
  cues.json      which spoken phrase each visual lands on
  deck/          index.html, lesson.html, decktalk-runtime.js (open a page for its scene index)
  media/         your clips, b-roll, markers.json
next: cp .env.example .env  (ELEVENLABS_API_KEY, ELEVENLABS_VOICE_ID), then `decktalk build`
      or `decktalk build --no-voice` to render with placeholder narration and no API key
```

## `decktalk preflight`

Checks a voiced build before it spends credits or records anything. It plans the takes, resolves every cue, and
estimates each reveal from frozen frames of the pages.

```text
decktalk preflight [-h] [--project PROJECT] [-v] [-q] [--json]
                   [--strict] [--exit-zero] [--only N] [--no-frames]
                   [--model MODEL] [--allow-unknown-cues]
```

| Option | Default | Meaning |
|---|---|---|
| `--only N` | every section | Checks only these sections. Repeatable. |
| `--no-frames` | off | Skips the frozen frames. No browser starts, and nothing is written. |
| `--model MODEL` | `[voice] model`, then `[narration] model` | Speech model to check the narration cache for. |
| `--allow-unknown-cues` | off | Does not count a cue id that is missing from its page. The table still notes it. |
| `--json`, `--strict`, `--exit-zero` | off | See [Output and exit flags](#output-and-exit-flags). |

**Reads** `script.md`, `cues.json`, `decktalk.toml`, the pages, and `build/narration`. Needs no key.
**Writes** `build/preflight/NN/slide-<id>-after-<cue>.png` and `slide-<id>-before-<cue>.png`, after it empties
`build/preflight`. `--no-frames` writes nothing. `preflight` never writes `cue-times.json` or `build/narration`.

`preflight` runs three checks.

1. **Takes.** It prints [the take plan](#the-take-plan) of `narrate --dry-run`. The plan says which sections a
   voiced run would voice, keep cached, or move, with the characters each section sends.
2. **Cues.** It resolves every cue phrase as `align` does, with the same notes. A cached or moved take resolves
   on its own words. A section that would be voiced resolves on estimated words at `silent_words_per_minute`, so
   its cue times are placeholders.
3. **Frames.** For each cue, it freezes the page just before the cue and at the cue, and compares the two frames
   as `verify` compares frames. For each page section with `seamless = true` after a page section, it
   compares the previous section's last frozen frame with this section's first one.

A frozen frame shows every reveal in its end state, with nothing in motion. So `chg %` estimates what `verify`
measures once the reveal has settled, with a control of 0. The verdicts use the `[verify]` limits.

| Verdict | When | Finding |
|---|---|---|
| `changed` | `chg %` is at least `thin_change_factor` times `min_changed_percent` and `min_margin_percent`. | none |
| `THIN CHANGE?` | `chg %` passes both floors, but not `thin_change_factor` times one of them. | uncertain |
| `NO CHANGE` | `chg %` is below `min_changed_percent` or `min_margin_percent`. | certain |
| `skipped` | Nothing was compared. The reason follows the verdict. | none |
| `ok` | A seam changes at most `max_pop_percent`. | none |
| `POP AT CUT` | A seam changes more than `max_pop_percent`. | certain |

| Reason | Meaning |
|---|---|
| `AT_SECTION_START` | The cue fires within the first frame, so no frame comes before it. |
| `NO_SLIDE` | No slide of the scene owns the cue. |
| `NOT_IN_SLIDE_CUES` | A slide owns the cue by its id prefix, and its `owns` list and `preview` object do not name it. A freeze stops only at a listed cue. |
| `NO_CATALOG` | The page is missing, or its catalog registers the scene with no slides and cues. |
| `OPTED_OUT` | `cues.json` sets `"verify": false` on the cue. |
| `NO_CUES` | A seam only. A side of the cut has no resolved cue. |
| `CLIP` | A seam only. A side of the cut is a clip, which `verify` checks after `assemble`. |

- The frames follow cue mode. The first cued slide mounts at t=0, and every other slide mounts at its earliest cue.
  The frame before a cue that mounts its slide shows the slide that was on screen.
- A freeze fires a slide's cues in preview order. When the cue times run in another order, the row notes that
  the frames may differ from the recording.
- The estimate sees no motion, no camera push, and no close neighbor cue. `verify` measures those on the final mp4.
- The frames need `catalog[].cues` and `&before=` from [the runtime](/reference/runtime#url-parameters).

| Exit | When |
|---|---|
| 0 | No certain finding, and no uncertain finding with `--strict`. |
| 1 | An unfilled placeholder, `UNRESOLVED`, `UNKNOWN CUE` without `--allow-unknown-cues`, `NO CHANGE`, or `POP AT CUT`. With `--strict`, also `THIN CHANGE?` or speech shorter than `min_seconds`. An error also exits 1. |

## `decktalk build`

Runs all seven stages in order and prints each stage's table.

```text
decktalk build [-h] [--project PROJECT] [-v] [-q] [--no-voice] [--force]
               [--only N] [--no-soundscape] [--no-loudness] [--strict]
               [--allow-unresolved-cues] [--allow-unknown-cues] [--preset PRESET]
               [--crf CRF]
```

| Option | Default | Meaning |
|---|---|---|
| `--no-voice` | off | Uses estimated word times and writes a click track. Needs no key. Stops when `build/narration/takes.json` holds voiced takes, unless `--force` is on. |
| `--force` | off | Voices every section again. Spends credits on every section. With `--no-voice`, replaces the voiced takes with click tracks. |
| `--only N` | every section | Records, measures, and checks only these sections. Repeatable. |
| `--allow-unresolved-cues` | off | Continues when a cue phrase is not found. |
| `--allow-unknown-cues` | off | Continues when a cue id is not in its page. |
| `--strict` | off | Fails on a missing recording, a missing clip without `optional = true`, or a recording that `measure` has not read since it was recorded. In a voiced build, also fails on a loudness miss. |
| `--no-soundscape` | off | Mixes narration and clip audio only. |
| `--no-loudness` | off | Skips the loudness pass. |
| `--preset PRESET` | `[video] preset` | x264 preset for this run. |
| `--crf CRF` | `[video] crf` | x264 quality for this run. |

Note: with `--only`, `narrate` still runs on every section and `assemble` still uses every section.
Recordings of other sections stay as they are. A build without voice stops when the project has voiced
takes, as [A build without voice and a voiced build](/guides/rebuild-one-section#a-build-without-voice-and-a-voiced-build)
explains.

**Reads** and **writes** what each stage reads and writes, below.

| Stage | `build` exits 1 when | Override |
|---|---|---|
| `narrate` | With `--no-voice`, `build/narration/takes.json` holds voiced takes. The build stops before it writes anything. | `--force`, or build in a copy of the project |
| `align` | A cue phrase is not found. The build stops after the align table. | `--allow-unresolved-cues` |
| `align` | A cue id is not in its page. The build stops after the align table. | `--allow-unknown-cues` |
| `check` | A page threw an error or has no catalog (`PAGE ERROR`). The build stops after the check table. | none |
| `assemble` | With `--strict`, a recording is missing, or a clip is missing from a section without `optional = true`. | Set `optional = true`, or leave out `--strict`. |
| `assemble` | With `--strict`, a recording has no measurement that matches it (`STALE MEASUREMENT`). | Run `decktalk measure --only N`, or leave out `--strict`. |
| `verify` | A section starts black (`BLACK`), speech is still sounding at a cut (`SPEECH AT CUT`), or the picture jumps at the cut into a section with `seamless` (`POP AT CUT`). | none |
| any | A stage raises an error. | none |

`build` does not measure cues. It exits 0 on `TRUNCATED`, `STALLED`, `NO COVER`, `BLACK?`, and
`KATEX?`. To gate a script on the whole video, run `check` and `verify` after the build, as
[Build in CI and offline](/guides/ci-and-offline) shows.

## Stages

`build` runs these seven commands in this order. Each one also runs on its own.

### `decktalk narrate`

Voices the script and writes each section's audio and word times.

```text
decktalk narrate [-h] [--project PROJECT] [-v] [-q] [--only N]
                 [--force] [--allow-placeholders] [--dry-run] [--json]
                 [--no-voice] [--model MODEL]
```

| Option | Default | Meaning |
|---|---|---|
| `--only N` | every spoken section | Voices only these sections. Repeatable. |
| `--force` | off | Ignores the narration cache. Spends credits on every section it voices. With `--no-voice`, replaces voiced takes. |
| `--allow-placeholders` | off | Voices a section that still has a `[CAPS]` placeholder. |
| `--dry-run` | off | Prints each section's text, the voice settings, the table, and the take plan. Sends nothing. |
| `--json` | off | With `--dry-run`, prints the take plan as one JSON object on stdout. Without `--dry-run`, exits 2. |
| `--no-voice` | off | Writes a click track with estimated word times. Needs no key. Stops when `build/narration/takes.json` holds voiced takes, unless `--force` is on. |
| `--model MODEL` | `[voice] model`, then `[narration] model` | Speech model id for this run. |

**Reads** `script.md`, `decktalk.toml`, and `.env`. `--no-voice` and `--dry-run` need no key.
**Writes** `build/narration/NN-slug.mp3`, `NN-slug.words.json`, `takes.json`, `narration.mp3`, and
`timeline.json`. `--dry-run` writes nothing.

- `narrate` never voices a clip section.
- `narrate` caches each section by provider, voice id, model, output format, voice settings, and text.
- `--only` rebuilds `narration.mp3` and `timeline.json` from every voiced section, not only the named ones.
- `--only` with no spoken section fails, for example `no spoken sections match [5]; spoken sections are [1, 2, 3, 4, 6, 8, 9]`.
- A placeholder fails a voiced run with `unfilled placeholders [...] in the script`.

The first table gives each section's word count, estimate (`est`), time budget (`target`), and audio
length (`actual`). The second table is the timeline in `narration.mp3`.
[script.md](/reference/script-md#length) gives the estimate formulas.

| Exit | When |
|---|---|
| 0 | Every target section is voiced or cached. |
| 1 | An error: no script, no sections, a section with no `[[section]]`, a placeholder, a missing key, or a provider error. |

#### The take plan

`--dry-run` checks the narration cache the way a voiced run does, and ends with the take plan. Each
section gets one take status.

| Take | Meaning |
|---|---|
| `synthesize` | A voiced run sends the section to the voice and spends its characters. |
| `cached` | A voiced run uses the section's take as it is. |
| `moved` | A take of the same text under another section number is copied to this section. No request is sent. |
| `unknown` | The speech provider could not be set up, so the cache cannot be checked. The `note` line says why. |

A `synthesize` row gives its reason: `no take yet`, `only a silent take exists`,
`the text, voice, model, or voice settings changed`, `the file name changed from <file>`,
`the mp3 or the words file is missing`, or `forced`. `sent` counts the characters the voice receives,
with dashes and break tags. `spoken` counts the spoken words' characters.

Without a key, a project with no voiced take plans every section as `synthesize`. A project with voiced
takes plans them as `unknown`, because the cache key needs the voice id.

With `--json`, the payload under `narrate` has these keys.

| Key | Meaning |

### `decktalk align`

Resolves each cue phrase to a cue time and writes `cue-times.json`.

```text
decktalk align [-h] [--project PROJECT] [-v] [-q] [--json] [--strict]
               [--exit-zero] [--allow-unknown-cues]
```

| Option | Default | Meaning |
|---|---|---|
| `--allow-unknown-cues` | off | Does not count a cue id that is missing from its page. The table still notes it. |
| `--json`, `--strict`, `--exit-zero` | off | See [Output and exit flags](#output-and-exit-flags). |

**Reads** `takes.json`, the words files, `cues.json`, and each page. **Writes** `cue-times.json` and
`cue-times.anchors.json`, even when it exits 1.

`align` looks for each cue id in its page as a quoted literal, in single quotes, double quotes, or
backticks. A `data-cue` value, a key of a slide's `preview` object, and a handler key all count.
[Cues](/concepts/cues#matching-rules) gives the phrase matching rules.

The table columns are `sec`, `speech` (the speech end in seconds), `need` (`min_seconds`), and
`cues` (each `id@seconds`). A note line starts with `!`.

| Note | Finding | Exit |
|---|---|---|

### `decktalk record`

Records each page section in headless Chromium to a webm.

```text
decktalk record [-h] [--project PROJECT] [-v] [-q] [--only N]
                [--seconds SECONDS] [--settle SETTLE] [--no-cues]
```

| Option | Default | Meaning |
|---|---|---|
| `--only N` | every page section | Records only these sections. Repeatable. |
| `--seconds SECONDS` | section span plus `record_margin_seconds` | Records every section for this long. Works with no timeline. |
| `--settle SETTLE` | `[record] settle_seconds` (0.5) | Least seconds after the page is ready before narration t=0. The recorder also waits for `[record] min_cover_seconds`. |
| `--no-cues` | off | Plays the page in preview instead of passing `?cues=`. |

**Reads** `timeline.json` (not with `--seconds`), `cue-times.json` (not with `--no-cues`), and the pages.
**Writes** `build/recordings/NN.webm` and its recording log `recordings/NN.json`.

- `record` prints no table. It logs one `[rec ]` line per section and every page warning as `[page]`.
- `record` skips a page section that has no span and logs `no narration span yet; skipped`.
- If the page stalls after narration t=0 for longer than `[record] stall_ms` (150), `record` records the section again.
- `record` tries again up to `[record] retries` (2) times.

| Exit | When |
|---|---|
| 0 | Every matched section is recorded. |
| 1 | No timeline and no `--seconds`, a page file is missing, or no page section matches. |

### `decktalk measure`

Finds narration t=0 in each recording and writes it to the recording log.

```text
decktalk measure [-h] [--project PROJECT] [-v] [-q] [--only N]
```

| Option | Default | Meaning |
|---|---|---|
| `--only N` | every recording | Measures only these sections. Repeatable. |

**Reads** each webm and its recording log. **Writes** `t0_seconds` and `t0_method` into the recording log.

`measure` scans the first `[record] cover_scan_seconds` (4.0) of the recording and finds the last magenta
frame. Narration t=0 is one frame after it. The table columns are `trim` (t=0 in the webm),
`wall` (the recorder's own clock estimate), and `method`.

| Method | Meaning |
|---|---|
| `cover (N magenta frames)` | Found the cover. |
| `NO COVER: first paint + settle` | No cover. The first painted frame plus `settle_seconds`. |
| `NO COVER: fallback guess + settle` | No painted frame. `fallback_first_paint_seconds` (1.1) plus `settle_seconds`. |
| `no frames read; fallback` | ffmpeg read no frames. The same fallback. |

| Exit | When |
|---|---|
| 0 | Every recording is measured. |
| 1 | No recordings exist. |

### `decktalk check`

Checks each recording's length, brightness, and recorder warnings.

```text
decktalk check [-h] [--project PROJECT] [-v] [-q] [--json] [--strict]
               [--exit-zero] [--only N]
```

| Option | Default | Meaning |
|---|---|---|
| `--only N` | every recording | Checks only these sections. Repeatable. |
| `--json`, `--strict`, `--exit-zero` | off | See [Output and exit flags](#output-and-exit-flags). |

**Reads** each webm and its recording log. **Writes** nothing.

Each row describes one recording.

| Column | Meaning |
|---|---|
| `webm_s` | Recorded seconds. |
| `want_s` | Requested seconds. |
| `Y10`, `Y50`, `Y90` | Average luma at 10, 50, and 90 percent of the recording. |
| `MAX50` | Brightest luma at the middle of the recording. |
| `verdict` | One or more verdicts from the table below. |

| Verdict | Finding | Meaning |
|---|---|---|
| `ok` | none | No finding. |
| `PAGE ERROR` | certain | The page threw an uncaught error, or has no `window.__decktalk.catalog`. `build` stops. |
| `STALLED <ms>ms` | certain | A frame gap after narration t=0 exceeded `[record] stall_ms` (150) on the last try. |
| `TRUNCATED` | certain | Shorter than requested by more than `[record] truncated_slack_seconds` (0.5). |
| `NO COVER` | certain | `measure` found no cover. The trim is a guess. |
| `BLACK?` | uncertain | `MAX50` is below `[record] black_ymax` (40). |
| `KATEX?` | uncertain | A page warning contains "katex" or "data-tex", in any case. |

Note: one row can show several verdicts, separated by spaces. The JSON lists them in `verdicts` and
puts the stall length in `stall_ms`.

| Exit | When |
|---|---|
| 0 | No certain verdict, and no uncertain verdict with `--strict`. |
| 1 | A certain verdict, an uncertain verdict with `--strict`, or no recordings. |

### `decktalk assemble`

Cuts, mixes, and writes the final video with its captions and chapters.

```text
decktalk assemble [-h] [--project PROJECT] [-v] [-q] [--no-soundscape]
                  [--no-loudness] [--strict] [--preset PRESET]
                  [--crf CRF]
```

| Option | Default | Meaning |
|---|---|---|
| `--no-soundscape` | off | Mixes narration and clip audio only. No music, ambience bed, or sound effects. |
| `--no-loudness` | off | Skips the loudness pass. |
| `--strict` | off | Fails on a missing recording, a missing clip without `optional = true`, or a recording that `measure` has not read since it was recorded. In a voiced build, also fails on a loudness miss. |
| `--preset PRESET` | `[video] preset` | x264 preset for this run. `veryfast` is for drafts. |
| `--crf CRF` | `[video] crf` | x264 quality for this run. |

**Reads** `timeline.json`, `takes.json`, `cue-times.json`, the recordings and recording logs, the clips, the
markers file, the music, the ambience bed, and the sound effects. **Writes**
`build/sections/NN.mp4`, `<name>.mp4`, `<name>.srt`, `<name>.vtt`, `<name>.chapters.txt`, and
`build/out/slates/`, plus a copy named `<name>-YYYYMMDD-HHMM.mp4` when `[output] timestamped_copy` is on.

- Without `--strict`, a missing clip plays a titled slate for `slate_seconds`, and a missing recording plays black.
- `assemble` trims each recording at the `t0_seconds` that `measure` wrote. If `measure` has not read the
  recording since it was recorded, `assemble` prints `STALE MEASUREMENT`. The section may then play early or late.
  Without `--strict`, `assemble` warns and continues. With `--strict`, it stops.
- A missing music file, ambience bed, markers file, or sound effect logs a warning and plays without it.
- A build without voice skips the loudness pass, so `--strict` has no loudness to fail on.
- `assemble` prints the final path and length on stdout.

| Exit | When |
|---|---|
| 0 | The final video is written. |
| 1 | No timeline, a page section with no span, or a `--strict` failure. |

### `decktalk verify`

Checks section starts, cuts, cut continuity, and cues in the final video.

```text
decktalk verify [-h] [--project PROJECT] [-v] [-q] [--json] [--strict]
                [--exit-zero] [--only N]
                [SECTION:CUE ...]
```

| Option | Default | Meaning |
|---|---|---|
| `SECTION:CUE ...` | every cue in `cue-times.json` | Checks only these cues, such as `8:7.1checked`. |
| `--only N` | every section | Keeps only the cues of these sections. Starts and cuts are always checked. Repeatable. |
| `--json`, `--strict`, `--exit-zero` | off | See [Output and exit flags](#output-and-exit-flags). |

**Reads** `build/sections/NN.mp4`, `build/out/<name>.mp4`, `narration.mp3`, `timeline.json`,
`cue-times.json`, `cue-times.anchors.json`, `takes.json`, and `cues.json`. **Writes** nothing.

| Check | Passes when | Keys in `[verify]` |
|---|---|---|
| Start | The brightest luma 0.2 s after the section start is above 60. | `after_dip_seconds`, `visible_ymax` |
| Cut | Narration RMS in the last 0.15 s before the cut is at most -40 dBFS. | `cut_window_seconds`, `cut_max_db` |
| Continuity | For a section with `seamless = true`, the frames on each side of the cut differ by at most 0.1 percent. | `max_pop_percent`, `diff_level` |
| Cue | The change test passes, and the onset is within the offset limit. After a build without voice, `a/v` is within the a/v limit too. | [verify reference](/reference/verify#cues) |

- With no cue arguments, `verify` checks every cue in `cue-times.json`, by section and then by cue time.
- With no cue arguments, `verify` skips a cue that `cues.json` marks `"verify": false`.
- Named cues run in the order given, positional cues first. A named cue runs even when it is opted out.
- `--only` also filters named cues. A named cue outside `--only` gets no row.
- The `verify` stage inside `build` checks starts, cuts, and continuity, and no cue.

`verify` prints up to four tables: section starts, cuts, cut continuity, and cues. The continuity table appears
only when a section sets `seamless`. A clip section has a start row but
no cut row. `cut at` is where the section's narration ends in the final video. The cue table gains an
`a/v` column only when at least one measured cue has an `a/v` value. The JSON `silent` key says if
the build was silent. [verify](/reference/verify#cues) defines each column.

| Result | Finding | Meaning |
|---|---|---|
| `ok` | none | The section start shows content. |
| `BLACK` | certain | The brightest luma at the start probe is at most `visible_ymax`. |
| `quiet` | none | The cut has no speech. |
| `SPEECH AT CUT` | certain | Narration RMS before the cut is above `cut_max_db`. |
| `POP AT CUT` | certain | The picture jumps at the cut into a section with `seamless = true`. |
| `changed` | none | The change test passed, and the onset is within the offset limit or no onset was found. |
| `THIN CHANGE?` | uncertain | Like `changed`, but the changed share or the margin is below `thin_change_factor` (3) times its floor. |
| `OFF CUE` | certain | The change test passed, but the offset column or the `a/v` column is past its limit. |
| `NO CHANGE` | certain | The change test failed. |
| `UNRESOLVED` | certain | A named cue is not in `cue-times.json`. |
| `skipped` | none | Nothing was measured. The reason follows the verdict. |

Note: `OFF CUE` prints no distance. Compare the offset column with 80 ms (`max_offset_frames`) and the
`a/v` column with 120 ms (`max_av_frames`). A measured cue with no click shows `-` in the `a/v` column
and has the JSON reason `NO_CLICK`. `NO_CLICK` is not a failure.

| Reason | Cause | Fix |
|---|---|---|
| `OPTED_OUT` | `cues.json` sets `"verify": false` on the cue. | Name the cue as `SECTION:CUE` to measure it. |
| `REFERENCE_CLAMPED` | No reference frame fits between the floor and one frame before the cue. Usual for a `$start` cue. | Check the reveal by eye with `decktalk screenshots --slide ID --after CUE`. |
| `SECTION_NOT_ASSEMBLED` | `build/sections/NN.mp4` does not exist. | Run `decktalk assemble`. |
| `TOO_CLOSE_TO_END` | Every probe falls later than 0.05 s before the section end. | Check the reveal by eye with `decktalk screenshots --slide ID --after CUE`. |

[verify](/reference/verify#skipped-rows) explains each reason.

| Exit | When |
|---|---|
| 0 | Every start, cut, and measured cue passed. |
| 1 | A certain result, a malformed `SECTION:CUE`, or no assembled video. |

## Clip commands

### `decktalk words`

Prints each spoken section's words, with times in seconds after the section starts.

```text
decktalk words [-h] [--project PROJECT] [-v] [-q] [--only N] [--json]
```

| Option | Default | Meaning |
|---|---|---|
| `--only N` | every spoken section | Prints only these sections. Repeatable. |
| `--json` | off | Prints one JSON object on stdout instead of the table. |

**Reads** `timeline.json`, and `takes.json` for the script's spelling. **Writes** nothing.

- Each time counts from the section's own start, as `?words=` and `cue-times.json` do. [Time bases](/reference/artifacts#time-bases) explains the clocks.
- A section's `lead_seconds` counts, so its first word starts after the lead.
- Each row gives the word's start, its end, and the word with the script's punctuation and case.
- After a build without voice, the times are estimates, and each section header says `estimated`.
- A page that prints real word times can take them from this output.

| Exit | When |
|---|---|
| 0 | The words are printed. |
| 1 | No `timeline.json`, or an `--only` section with no words. |

{/* sample: decktalk words --only 1 after decktalk build --no-voice on a fresh scaffold, first rows */}

```text
== 01 Open  (17.80s, estimated)
  start     end  word
  0.700   1.225  A
  1.245   1.770  bowl.
  1.790   2.314  A
  2.334   2.859  ball.
  2.879   3.404  Watch
```

This shape shows the `--json` payload. The values are types, not a sample.

```jsonc
"words": {
  "sections": [ { "key": "01", "section": 1, "title": "string", "lead_seconds": 0.0, "duration": 0.0,
                  "estimated": true,
                  "words": [ { "word": "string", "text": "string", "start": 0.0, "end": 0.0 } ] } ]
}
```

`word` is the word as the voice returned it, with punctuation removed. `text` is the same word with the script's
punctuation and case.

### `decktalk clip`

Cuts a span of a built page section into a video file and a words file, for a clip section.

```text
decktalk clip [-h] [--project PROJECT] [-v] [-q] --start SECONDS
              --end SECONDS --out OUT [--words WORDS] [--gain DB]
              [--hold SECONDS] [--preset PRESET] [--crf CRF]
              section
```

| Option | Default | Meaning |
|---|---|---|
| `section` | required | The page section to cut from. |
| `--start SECONDS` | required | Start of the span, in seconds after the section starts. |
| `--end SECONDS` | required | End of the span, in seconds after the section starts. |
| `--out OUT` | required | The clip file, relative to the project, such as `media/open.mp4`. |
| `--words WORDS` | `--out` with `.words.json` | The words file, relative to the project. |
| `--gain DB` | 0 | Gain on the clip's sound, in dB. |
| `--hold SECONDS` | 0 | Holds the last frame this long, in silence. |
| `--preset PRESET`, `--crf CRF` | `[video]` | x264 settings for this run. |

**Reads** `build/sections/NN.mp4`, the section's mp3, `takes.json`, and `timeline.json`. **Writes** the clip
and its words file.

- `--start` and `--end` use the clock that [`decktalk words`](#decktalk-words) prints. Run it first to pick the span.
- The picture is the section video's frames from `--start` to `--end`, each time rounded to the nearest frame.
- The sound is the section's mp3 over the same span. A span inside the section's `lead_seconds` is silent.
- The sound fades in and out over 10 ms, so a cut inside a word does not click.
- The clip is H.264 video and AAC audio, at the frame rate and sample rate in `[video]`.
- The words file lists each word wholly inside the span, in seconds after the clip starts, with the script's
  punctuation and case. A word that the span cuts in two is left out, and `clip` prints a warning.
- After a build without voice, the sound is the click track and the words are estimates, and `clip` prints a warning.

| Exit | When |
|---|---|
| 0 | The clip and its words file are written. |
| 1 | No section video, no narration, a clip section, or a span that ends past the section video. |
| 2 | A missing `section`, `--start`, `--end`, or `--out`. |

{/* sample: decktalk clip 1 --start 2.87 --end 8.32 --hold 0.5 --out media/count.mp4 after decktalk build --no-voice on a fresh scaffold */}

```text
section 01: the narration is a silent placeholder, so the word times are estimates
wrote media/count.mp4  (5.92s: frames 72 to 207 of sections/01.mp4, 2.88 to 8.32s, hold 0.48s, gain +0 dB)
wrote media/count.words.json  (10 words)
use it in a clip section: clip = "media/count.mp4" and words = "media/count.words.json"
```

The line gives the clip's length with the hold, the frames it took, the span after rounding to whole frames, the
hold, and the gain. `--start 2.87` rounds to frame 72, at 2.88 s. `--hold 0.5` rounds to 12 frames, which is 0.48 s.

[Cut a clip from a build](/guides/clip-section#cut-a-clip-from-a-build) puts the clip in a clip section.

## Output and exit flags

Six read-only commands print their result as JSON. Each takes the options that its own findings can
reach, so `status`, which judges nothing, takes `--json` alone, and `doctor`, whose every row is
certain, takes `--json` and `--exit-zero`.

| Option | Default | Meaning |
|---|---|---|
| `--json` | off | Prints one JSON object on stdout instead of the tables. Logs still go to stderr. |
| `--strict` | off | Also exits 1 on an uncertain finding. `align`, `preflight`, `check` and `verify` take it. |
| `--exit-zero` | off | Exits 0 on findings. An error still exits 1. Every command but `status` takes it. |

An uncertain finding is a verdict that ends in `?`. In `align` and `preflight`, speech shorter than `min_seconds` is
also uncertain. On `assemble` and `build`, `--strict` has a different meaning. It fails on a missing
recording, or a missing clip in a section without `optional = true`.

This shape shows the JSON envelope. The values are types, not a sample.

```jsonc
{
  "command": "verify",
  "version": "<version>",
  "ok": true,
  "findings": { "certain": 0, "uncertain": 0 },
  "verify": { }   // the payload, named after the command
}
```

| Key | Type | Meaning |
|---|---|---|
| `command` | string | Command that ran. |
| `version` | string | DeckTalk version. |
| `ok` | boolean | True when the command exits 0 without `--exit-zero`. `--strict` counts. |
| `findings.certain` | integer | Certain findings. Any one exits 1. |
| `findings.uncertain` | integer | Uncertain findings. They exit 1 only with `--strict`. |

| Command | Payload |
|---|---|
| `doctor` | `components`: a list of `{name, ok, detail}`, one per row. |
| `status` | The shape under [`decktalk status`](#decktalk-status). |
| `align` | `estimated`, `cue_times_file`, `unresolved`, `unknown`, and `sections`. |
| `check` | `recordings`: a list of `{key, file, duration, wanted, y10, y50, y90, max50, verdicts, stall_ms, page_errors}`. |
| `verify` | `final`, `total_seconds`, `silent`, `starts`, `cuts`, `seams`, and `cues`. |
| `preflight` | `voice`, `note`, `placeholders`, `takes`, `totals`, `cue_times`, `cues`, `seams`, and `frames`. |
| `narrate --dry-run --json` | `voice`, `note`, `sections`, and `totals`, as [the take plan](#the-take-plan) gives. `ok` is always true. |
| `words --json` | `sections`, as [`decktalk words`](#decktalk-words) gives. `ok` is always true. |

Note: each `cue_times` section is `{key, speech_end, min_seconds, skipped, cues, notes}`. Each note is
`{cue, verdict, detail}`, where `verdict` is `UNRESOLVED`, `UNKNOWN CUE`, or `null`. Each `verify` cue row
is `{section, cue, cue_seconds, final_seconds, changed_percent, control_percent, offset_ms, av_ms,
verdict, reason}`. [verify](/reference/verify#json-fields) defines them. Each `preflight` cue row is `{section,
cue, cue_seconds, slide, changed_percent, verdict, reason, detail, note, before, after}`, and each seam row is
`{key, changed_percent, verdict, reason, detail, last, first}`. The `preflight` `takes` rows are the take plan rows
without `text`, and `cue_times` is the `align` payload without `cue_times_file`, plus `estimated_sections`.

- Every `key` is a two-digit section string such as `"03"`. A `verify` cue row's `section` is an integer.
- A value that does not exist is `null`. Every verdict is the name that the table prints.
- Paths are relative to the project root, with forward slashes. `project.root`, `doctor` details, and paths outside the project stay absolute.
- Only the JSON object goes to stdout, so `decktalk verify --json > verify.json` captures nothing else.

## Exit codes

| Code | Meaning |
|---|---|
| 0 | Success, or `--exit-zero` on a command with findings. |
| 1 | An error printed as `error: …` on stderr, or a finding in the table below. |
| 2 | A usage error, such as an unknown option, a missing command, or `screenshots --after` without one `--slide`. |
| 130 | Interrupted. |

| Command | Exits 1 on (certain) | Exits 1 only with `--strict` (uncertain) |
|---|---|---|
| `doctor` | A `MISSING` row. | Never, so `doctor` takes no `--strict`. |
| `align` | `UNRESOLVED`, and `UNKNOWN CUE` without `--allow-unknown-cues`. | Speech shorter than `min_seconds`. |
| `check` | `PAGE ERROR`, `STALLED`, `TRUNCATED`, `NO COVER`. | `BLACK?`, `KATEX?` |
| `verify` | `BLACK`, `SPEECH AT CUT`, `POP AT CUT`, `OFF CUE`, `NO CHANGE`, `UNRESOLVED`. | `THIN CHANGE?` |
| `preflight` | An unfilled placeholder, `UNRESOLVED`, `UNKNOWN CUE` without `--allow-unknown-cues`, `NO CHANGE`, `POP AT CUT`. | `THIN CHANGE?`, speech shorter than `min_seconds`. |
| `status` | Never, so `status` takes neither flag. | Never. |
| `build` | See [`decktalk build`](#decktalk-build). | Not used. |
| Every other command | Only an error. | Not used. |

- `--exit-zero` makes `doctor`, `align`, `preflight`, `check`, and `verify` exit 0 on findings.
- With `--exit-zero`, the JSON `ok` key still says if the command passed.
- An error is not a finding. A `DeckTalkError` exits 1, even with `--exit-zero`.
- An unexpected exception prints `error: <type>: <message> (add -v for the traceback)` and exits 1.
- With `-v`, an unexpected exception prints its full traceback.
