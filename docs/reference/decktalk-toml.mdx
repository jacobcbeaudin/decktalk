Each project has one `decktalk.toml`. Every path in it is relative to the project
directory. An unknown top-level table fails the load, so a typo cannot silently do
nothing, and a value of the wrong type fails with the table and key named. The file has
two kinds of content. The document tables in this reference describe the presentation. The
[tuning tables](/reference/configuration) change how DeckTalk renders and are rarely
needed.

```toml decktalk.toml
[project]
name = "my-lesson"

[voice]
stability = 0.55

[[section]]
number = 0
title = "On camera"
clip = "media/open.mp4"

[[section]]
number = 1
title = "Open"
page = "deck/index.html"
scene = 1

[transition]
dips = [[0, 1]]

[mix]
underscore = "build/music/underscore.mp3"
```

## `[project]`

| Key | Default | Meaning |
|---|---|---|
| `name` | the directory name | The key sets the output name. The video lands at `build/out/<name>.mp4`, with `<name>.srt`, `<name>.vtt`, and `<name>.chapters.txt` beside it. |
| `script` | `script.md` | The key names the narration file. |
| `cues` | `cues.json` | The key names the cue file. The file is optional, and without it pages run their built-in timing. |
| `build` | `build` | The key names the directory for generated files. |

## `[voice]`

The voice settings for this presentation. The voice id and the API key are secrets, so
they live in `.env` as `ELEVENLABS_VOICE_ID` and `ELEVENLABS_API_KEY`, or in the
environment.

| Key | Default | Meaning |
|---|---|---|
| `provider` | `elevenlabs` | The key names the speech provider by the name it registered. ElevenLabs is the built-in provider. |
| `model` | `[narration]` `model`, which defaults to `eleven_multilingual_v2` | The key sets the ElevenLabs model id. The `--model` flag overrides it for one run. |
| `stability` | 0.55 | Lower values vary more between takes. |
| `similarity_boost` | 0.75 | The value sets how closely the voice follows the clone. |
| `style` | 0.0 | The value sets style exaggeration, and zero is the most stable. |
| `speaker_boost` | true | The value turns ElevenLabs' speaker boost on or off. |
| `speed` | 1.0 | The value sets the speaking rate. |

A change to any of these changes the cache key of every section, so the next build
synthesizes every section again and spends credits on all of them.
[Requirements and costs](/requirements) lists every change that does.

## `[[section]]`

Write one table per `## N.` section of the script. The order in the file does not
matter, because DeckTalk sorts them by `number`, and a duplicate number fails the load.
Every script section must have one. A section is either a page or a clip, and a table
with both keys fails.

| Key | Applies to | Default | Meaning |
|---|---|---|---|
| `number` | both | required | The key holds the number that matches `## N.` in the script. |
| `title` | both | empty | The key sets the title shown on slates, in the status report, and as the chapter title. |
| `page` | page | required | The key names the HTML file, for example `deck/index.html`. |
| `scene` | page | the section number | The key sets the value the page receives as `?scene=`. It may be a number or a string. |
| `extra_seconds` | page | 0.3 | The key sets how long the recording runs past the narration. The margin keeps the cut off a frame that was never drawn. |
| `hold_seconds` | page | 0 | The key sets how long the last frame holds after the narration, by cloning it. Only the last page section may hold, because an earlier hold would push every later visual off its words. |
| `ambience` | page | false | The key sets whether the ambience bed plays under this section. |
| `params` | page | none | The table holds extra query parameters for the page, written as `[section.params]` with keys such as `theme = "dark"`. A `beats` key here replaces the resolved cues. |
| `clip` | clip | required | The key names your video file, which keeps its own audio. It is scaled and padded to the frame size. A clip may sit before, between, or after the page sections, and the narration pauses for a clip between page sections. [Add a clip section](/guides/clip-section#where-a-clip-may-sit) explains how. |
| `slate_seconds` | clip | 5 | The key sets how long the titled slate plays when the clip file is missing. |

A missing clip is not an error unless you pass `--strict`. A titled slate plays for
`slate_seconds` in its place, so a project builds before every asset exists.

A clip between two page sections plays as B-roll. The narration pauses when the clip
starts and resumes on the first frame of the next page section, so the words of every page
section stay on their picture.

## `[transition]`

| Key | Default | Meaning |
|---|---|---|
| `dips` | every cut | The key lists the boundaries that dip to black, written as `[[from, to], …]` section numbers. Leave the key out to dip at every cut, or set `[]` for no dips. A pair that names a section that does not exist fails the load. |
| `dip_seconds` | 0.15 | The key sets the fade length, quantized to whole frames. It applies to video only, and audio never dips. |
| `page_fades_in` | true | Pages fade themselves up, so DeckTalk adds no fade-in on their side of a dip. |

## `[mix]`

The mix is optional. Without this table the video carries narration and clip audio
only. [Sound](/concepts/sound) explains how the parts fit together.

| Key | Default | Meaning |
|---|---|---|
| `underscore` | none | The key names the music bed. DeckTalk loops it and ducks it under speech. |
| `underscore_db` | -24 | The key sets the bed level. |
| `underscore_duck_db` | -6 | The key sets the additional attenuation under speech. |
| `underscore_fade_in` | 2 | The key sets the fade-in length in seconds. |
| `underscore_fade_out` | 3 | The key sets the fade-out length in seconds. |
| `markers` | none | The key names a JSON file that swells or mutes the bed at spoken phrases. |
| `ambience` | none | The key names the ambience bed. It plays under sections that set `ambience = true`. |
| `ambience_db` | -20 | The key sets the ambience level. |
| `slate` | rendered | The key names a PNG to use instead of the rendered titled slate. |

### `[[mix.sfx]]`

One table per one-shot effect. [Put a sound effect on a cue](/guides/sfx-on-a-cue) walks
through one.

| Key | Default | Meaning |
|---|---|---|
| `file` | required | The key names the audio file. |
| `section` | required | The key holds the number of the section whose cue places the effect. The section must exist. |
| `cue` | required | The key names a cue id that `beats` resolved for that section. |
| `db` | -16 | The value sets the effect's level. |
| `offset` | 0 | The key holds seconds added to the cue time. |

### `[mix.loudnorm]`

The targets for the loudness pass, which [How it works](/concepts/how-it-works#loudness)
describes. The keys are accepted in upper or lower case.

| Key | Default | Meaning |
|---|---|---|
| `I` | -16 | The value sets the integrated loudness in LUFS. |
| `TP` | -1.5 | The value sets the true-peak ceiling in dBTP. |
| `LRA` | 11 | The value sets the loudness range in LU, which is passed to the measurement. |

## `[soundscape]`

These tables hold the prompts for `decktalk soundscape`, which generates sound with
ElevenLabs. Ambience and music write to the `ambience` and `underscore` paths named in
`[mix]`. When `[mix]` names none, they write to `build/sfx/ambience.mp3` and
`build/music/underscore.mp3`. Each effect writes to `build/sfx/<name>.mp3` unless its
`out` key says otherwise.

### `[soundscape.ambience]`

| Key | Default | Meaning |
|---|---|---|
| `text` | required | The text is the prompt. |
| `duration_seconds` | `[elevenlabs]` `ambience_seconds`, 25 | The key sets the length to request. The bed loops. |
| `prompt_influence` | `[elevenlabs]` `ambience_prompt_influence`, 0.3 | The key sets how closely the sound follows the prompt. |
| `model_id` | `[elevenlabs]` `sound_model` | The key names the sound model. |
| `out` | the `[mix]` path | The key sets where the file is written. |

### `[soundscape.sfx.<name>]`

| Key | Default | Meaning |
|---|---|---|
| `text` | required | The text is the prompt. |
| `duration_seconds` | `[elevenlabs]` `sfx_seconds`, 0.5 | The key sets the length to request. |
| `prompt_influence` | `[elevenlabs]` `sfx_prompt_influence`, 0.5 | The key sets how closely the sound follows the prompt. |
| `model_id` | `[elevenlabs]` `sound_model` | The key names the sound model. |
| `out` | `build/sfx/<name>.mp3` | The key sets where the file is written. |

### `[soundscape.music]`

| Key | Default | Meaning |
|---|---|---|
| `prompt` | required | The value is the prompt. |
| `seconds` | 360 | The value sets the length to request. A length longer than `max_music_chunk_seconds` is requested in chunks and crossfaded. |
| `force_instrumental` | true | The music has no vocals when the value is true. |
| `model_id` | `[elevenlabs]` `music_model` | The key names the music model. |
| `out` | the `[mix]` path | The key sets where the file is written. |

## Tuning tables

Any settings table can be overridden per project with a table of the same name, such
as `[video]` or `[record]`, or per shell with a `DECKTALK_<TABLE>_<FIELD>` variable.
[Configuration](/reference/configuration) lists every field with its default.
